# 爻语语法完整参考

> 本文是**语法参考**（查手册用）。想快速上手请看 [快速上手.md](快速上手.md)，
> 想了解内置函数细节请看 [内置函数.md](内置函数.md)。

爻语（Yao）是一门用中文单字作关键字的编程语言，解释器用 Python 标准库从零实现。

**设计要点**：值在前、名字在后（`42 名 答案` = 把 42 绑定到 答案），
块用 `【 】`，所有关键字只有一个汉字，不用 `=` 赋值。

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻语\解释器\exe\yao.exe 程序.yao      # 推荐：单文件，无依赖
> 爻语\解释器\exe\yao.exe 程序.yao        # 备选：开发时用，功能更全
> ```
>
> **能力差异**：`yao.exe`（C 版）支持语言核心语法、75 个内置函数里的 48 个，
> 但**不含** Web 服务、MQTT、Modbus TCP。做网页后端或工业物联请用 Python 版。
> 完整对照见 [手册.md](手册.md#解释器版本对照)。

## 一、词法

### 1.1 注释

```text
注 这是注释，到行尾
1 + 2 注 注释也可以跟在语句后面
```

`注` 后面必须有空白或换行才被当作注释标记，否则是普通标识符的一部分。

### 1.2 标识符

可以是**汉字、字母、下划线、数字**（数字不能开头）：

```yao
1 名 甲
2 名 answer
3 名 _临时
4 名 值1
```

**不能用**关键字作标识符（29 个，见附录）。也不能有以关键字结尾的名字冲突，
如 `回答` 里的 `答` 不是关键字所以没问题，但 `名` 单独就不能当变量名。

### 1.3 字面量

| 类型 | 写法 | 说明 |
|---|---|---|
| 数 | `42`、`3.14`、`-7` | 整数与浮点不区分 |
| 字 | `"你好"`、`"a\nb"` | 双引号，支持 `\n \t \r \\ \" \'` |
| 真/假 | `真`、`假` | 布尔 |
| 空 | `空` | 空值（类似 null） |
| 列 | `[1, 2, 3]`、`[]` | 列表 |
| 表 | `{ "甲" ⇒ 1, "乙" ⇒ 2 }`、`{}` | 字典（键值对） |

### 1.4 符号

**双字符**（优先匹配）：`==` `!=` `<=` `>=` `⇒` `▷` `->` `**` `//`

**单字符**：`+ - * / % < > ( ) [ ] { } , : . ^ = !`

**全角自动映射**（写中文时不用切输入法）：

| 全角 | 半角 |
|---|---|
| `（ ）` | `( )` |
| `［ ］` | `[ ]` |
| `｛ ｝` | `{ }` |
| `， ： ； 。` | `, : ; .` |
| `＝ ＋ － ＊ ／ ％` | `= + - * / %` |
| `＜ ＞ ！` | `< > !` |
| `“ ” ‘ ’` | `" " ' '` |
| `⇒` | `=>` |
| `▷` | `\|>` |

## 二、程序结构

### 2.1 一个文件

文件就是**一串语句**，顺序执行。没有 `main` 函数，没有 `package` 声明。

```yao
注 我的第一个爻语程序
显("你好，爻语")
42 名 答案
显("答案是 ", 答案)
```

### 2.2 块

块用 `【 】` 包裹，用于函数体、条件分支、循环体：

```yao
匠 打招呼(谁) 【
  显("你好，", 谁)
】
```

块的缩进**不影响语义**（不像 Python），但为可读性建议缩进 2 格。

### 2.3 语句分隔

**换行即语句结束**，不需要分号。同一行写多条语句只有一种情况——
`判` 的分支臂后面跟单条语句：

```yao-fragment
判 【 真 ⇒ 显("是") 它 ⇒ 显("否") 】
```

## 三、变量

### 3.1 绑定（定义）—— `名`

**值在前，名字在后**：

```yao
42 名 答案
"你好" 名 问候
[1, 2, 3] 名 数字们
{ "甲" ⇒ 1 } 名 表
```

`名` 在当前作用域**新建**绑定（重复定义会覆盖）。

### 3.2 赋值（修改）—— `易`

同样值在前：

```yao-fragment
答案 + 1 易 答案
"改过了" 易 问候
```

`易` 会沿作用域链找**已有的**变量并修改。找不到会报错（这时应该用 `名`）。

```yao-fragment
0 名 计数
计数 + 1 易 计数        注 对：计数 已存在

注 下面这行会报错，因为 计数2 没定义过
注 计数2 + 1 易 计数2
```

### 3.3 作用域

- 函数有独立作用域
- `循` / `遍` 的循环体**每轮建新作用域**
- `判` 的分支体**不建新作用域**（继承当前）

```yao
0 名 外部
匠 测试() 【
  10 名 外部     注 这是函数内的新变量，不影响外面
  归 外部
】
```

> **重要**：块内用 `名` 定义的是**局部变量**，出块就没了。
> 要跨块修改外层变量必须用 `易`。

## 四、运算符

### 4.1 算术

| 运算 | 写法 | 说明 |
|---|---|---|
| 加 | `甲 + 乙` | 数相加；字拼接；列合并 |
| 减 | `甲 - 乙` | 数值减 |
| 乘 | `甲 * 乙` | 数值乘；字 × 数 = 重复 |
| 除 | `甲 / 乙` | 浮点除，除零报错 |
| 取余 | `甲 % 乙` | |
| 负号 | `-甲` | 一元 |

```text
1 + 2 * 3         注 7（标准优先级）
"你" + "好"       注 "你好"
[1, 2] + [3]      注 [1, 2, 3]
"ab" * 3          注 "ababab"
```

### 4.2 比较

`==` `!=` `<` `<=` `>` `>=`

```text
1 == 1        注 真
显("甲" != "乙")  注 真
3 < 5         注 真
```

**类型不同的值 `==` 返回假**（不做隐式转换）。

### 4.3 逻辑

| 运算 | 写法 | 说明 |
|---|---|---|
| 且 | `甲 且 乙` | 短路 |
| 或 | `甲 或 乙` | 短路 |
| 非 | `非 甲` | |

```text
真 且 假      注 假
真 或 假      注 真
非 真         注 假
```

### 4.4 管道 `▷`

把左边的值作为右边函数的第一个参数：

```text
"你好" ▷ 长           注 等价于 长("你好")
[3, 1, 2] ▷ 排       注 等价于 排([3, 1, 2])
```

### 4.5 优先级（低 → 高）

```yao-fragment
1. 或
2. 且
3. 非
4. == != < <= > >=
5. + -
6. * / %
7. 一元 -
8. 后缀（调用 / 索引 / 成员）
```

括号 `( )` 可以改变优先级。

## 五、控制流

### 5.1 条件 `判`

**条件在 `判` 后面，各分支臂在块里**。臂的模式是**任意表达式**，
`它` 是兜底臂：

```yao
100 名 温度
判 温度 > 100 【
  真 ⇒ 显("太热")
  它 ⇒ 显("正常")
】
```

多臂（相当于 if / else if / else）：

```yao
85 名 分数
判 【
  分数 >= 90 ⇒ 显("A")
  分数 >= 80 ⇒ 显("B")
  分数 >= 60 ⇒ 显("C")
  它 ⇒ 显("D")
】
```

**臂体可以是块**：

```yao
120 名 温度
0 名 告警次数
判 温度 > 100 【
  真 ⇒ 【
    显("太热")
    告警次数 + 1 易 告警次数
  】
  它 ⇒ 空
】
```

### 5.2 条件循环 `循`

```yao
0 名 i
循 i < 5 【
  显(i)
  i + 1 易 i
】
```

**`循` 的条件在每轮开头检查。** 循环体里的 `易` 修改条件变量后，
**当前这一轮的剩余语句仍会执行完**，下一轮开头才检查条件：

```yao
真 名 继续
0 名 轮
循 继续 【
  轮 + 1 易 轮
  判 【 轮 >= 2 ⇒ 假 易 继续 它 ⇒ 空 】
  显("第 ", 轮, " 轮还是会执行完")     注 本轮照跑
】
```

要立即跳出必须用 `断`。

### 5.3 遍历 `遍`

```yao
遍 项 于 [10, 20, 30] 【
  显(项)
】
```

**遍历列时绑定的 `项` 是值，不是索引。**

遍历表时绑定的是**键**，要用 `键集()` 拿值：

```yao
{ "甲" ⇒ 1 } 名 表
遍 键 于 表 【
  显(键, " = ", 取(表, 键, 空))
】
```

### 5.4 区间循环 `环…自…至…步`

```yao
环 i 自 0 至 10 【
  显(i)         注 0..9
】

环 i 自 0 至 10 步 2 【
  显(i)         注 0 2 4 6 8
】
```

### 5.5 跳出与继续

| 语句 | 作用 |
|---|---|
| `断` | 跳出最近的循环 |
| `续` | 跳过本轮剩余，进入下一轮 |

> **`断` / `续` 只能在 `循`、`遍`、`环` 内部使用**，循环外写是语法错误。

### 5.6 提前返回 `归`

```yao
匠 找(列, 目标) 【
  遍 项 于 列 【
    判 项 == 目标 【
      真 ⇒ 归 真        注 提前返回
    】
  】
  归 假
】
```

`归` 在**嵌套块里也能从函数返回**（不只是退出块）。

## 六、函数

### 6.1 定义与调用—— `匠`

```yao
匠 加(甲, 乙) 【
  归 甲 + 乙
】

加(1, 2) 名 结果
```

调用就是 `函数名(参数们)`。没有参数也要写括号：`听()`。

### 6.2 匿名函数—— `节`

```yao-fragment
节 (x) 【 归 x * 2 】 名 加倍
显(加倍(21))      注 42
```

常作高阶函数的参数：

```yao
映([1, 2, 3], 节 (x) 【 归 x * x 】)    注 [1, 4, 9]
筛([1, 2, 3, 4], 节 (x) 【 归 x % 2 == 0 】)  注 [2, 4]
折([1, 2, 3], 节 (累, 项) 【 归 累 + 项 】, 0)  注 6
```

### 6.3 闭包

`节` 会捕获定义时的作用域：

```yao
匠 造计数器() 【
  0 名 计数
  归 节 () 【
    计数 + 1 易 计数
    归 计数
  】
】
造计数器() 名 计
显(计())      注 1
显(计())      注 2
```

### 6.4 递归

```yao
匠 阶乘(n) 【
  判 n <= 1 【
    真 ⇒ 归 1
    它 ⇒ 空
  】
  归 n * 阶乘(n - 1)
】
显(阶乘(5))    注 120
```

### 6.5 函数是一等值

函数可以存进变量、表、当参数传：

```yao
匠 甲() 【 归 1 】
匠 乙() 【 归 2 】
[甲, 乙] 名 函数们
取(函数们, 0, 空)()      注 1

{ "加点" ⇒ 节 () 【 归 "加" 】 } 名 操作
取(操作, "加点", 空)()   注 "加"
```

## 七、错误处理

### 7.1 抛出 `抛`

```yao
匠 检查(值) 【
  判 值 < 0 【
    真 ⇒ 抛 "值不能为负"
  】
  归 值
】
```

可以抛**任何值**（字、表、数）：

```yao-fragment
抛 { "类" ⇒ "业务错", "说明" ⇒ "库存不足" }
```

### 7.2 捕获 `试…捕…`

```yao
匠 检查(值) 【
  判 值 < 0 【
    真 ⇒ 抛 { "类" ⇒ "业务错", "说明" ⇒ "值不能为负" }
  】
  归 值
】

试 【
  检查(-1)
】 捕 误 【
  显("出错了：", 取(误, "说明", 误))
】
```

`误` 是错误对象（表），字段：

| 字段 | 说明 |
|---|---|
| `类` | 错误类型名（如 `"型误"`） |
| `说明` | 错误信息 |
| `行` `列` | 位置 |
| `栈` | 调用栈 |

### 7.3 收尾 `终`

```yao-fragment
试 【
  ...
】 捕 误 【
  ...
】 终 【
  显("无论成功失败都执行")
】
```

### 7.4 错误类型（14 种）

| 类名 | 触发场景 |
|---|---|
| `法误` | 语法错误 |
| `名误` | 未定义的名字 / 无法赋值 |
| `型误` | 类型不匹配 |
| `值误` | 值不合法 |
| `键误` | 键不存在 / 索引越界 |
| `算术误` | 除零等 |
| `参误` | 参数个数不对 |
| `引误` | 模块引用失败 |
| `路误` | 路由/路径问题 |
| `网误` | 网络错误 |
| `文件误` | 文件读写错误 |
| `编码误` | 编码问题 |
| `断言误` | `核` 断言失败 |
| `超时误` | 超时 |

## 八、模块

### 8.1 引用—— `引`

```yao-fragment
引 "工具.yao" 名 工具
工具.加法(1, 2)
```

`引` 加载文件并返回它的**导出表**。路径相对当前文件解析。

### 8.2 导出

模块里的**顶层绑定**自动导出（函数、变量都可以）：

```yao
注 工具.yao
匠 加法(甲, 乙) 【
  归 甲 + 乙
】
"1.0" 名 版本
```

引用后 `工具.加法(1,2)`、`工具.版本` 都可用。

> **注意**：`引` 是运行时加载。单文件应用不能靠 `引` 拆分成多个文件后
> 直接打包（除非把文件一起带上）。做独立 exe 时要合并成单文件。

## 九、完整示例

### 9.1 斐波那契

```yao
匠 斐(n) 【
  判 n <= 1 【
    真 ⇒ 归 n
    它 ⇒ 空
  】
  归 斐(n - 1) + 斐(n - 2)
】

0 名 i
循 i < 10 【
  显(斐(i))
  i + 1 易 i
】
```

### 9.2 统计词频

```yao
"苹果 香蕉 苹果 橘子 香蕉 苹果" 名 文本
{} 名 计数

遍 词 于 分(文本, " ") 【
  判 含(计数, 词) 【
    真 ⇒ 取(计数, 词, 0) + 1 易 计数[词]
    它 ⇒ 1 易 计数[词]
  】
】

遍 键 于 键集(计数) 【
  显(键, " 出现 ", 取(计数, 键, 0), " 次")
】
```

### 9.3 Web 服务

```yao-fragment
路("GET", "/api/时间", 节 (请) 【
  归 { "时间" ⇒ 今() }
】)

路("POST", "/api/回显", 节 (请) 【
  归 { "收到" ⇒ 请.体 }
】)

听(8795)
```

### 9.4 Modbus 控制

```yao-fragment
注 写调速寄存器（速度 × 100，注意用 舍 避免 229.9999 截断成 229）
250 名 寄存器值
写寄("127.0.0.1", 15020, 1, 0, 寄存器值) 名 果
判 取(果, "成", 假) 【
  真 ⇒ 显("已下发")
  它 ⇒ 显("失败：", 取(果, "错", ""))
】
```

### 10.2 语句一览

```yao-fragment

匠 名(参们) 【 体 】          定义函数
匠 名() 【 体 】             定义无参函数
节 (参们) 【 体 】            匿名函数
归 值                        函数返回
判 条件 【 臂们 】            条件
判 【 模式 ⇒ 体 … 它 ⇒ 体 】  多臂条件
循 条件 【 体 】              条件循环

```

### 10.3 易错点

| 坑 | 说明 |
|---|---|
| **值在前** | `42 名 答案` 不是 `答案 名 42` |
| **没有 `=`** | 赋值用 `易` |
| **`断` 只能在循环里** | 循环外写 `断` 是语法错误 |
| **`易` 不改变流程** | `假 易 继续` 后本轮剩余语句仍执行 |
| **块内 `名` 是局部** | 出块就没了，跨块要用 `易` |
| **`遍` 列绑值、表绑键** | 遍历表要配合 `键集()` |
| **换行不结束表达式** | `[] 名 x` 紧跟调用会被当索引 |
