# 爻语快速上手（15 分钟）

本教程所有代码都可以直接运行。准备一个文件 `入门.yao`，边写边跑：

```powershell
爻语\解释器\exe\yao.exe 跑 入门.yao
```

也可以不建文件，直接开交互式解释器：

```powershell
爻语\解释器\exe\yao.exe 台
```

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻语\解释器\exe\yao.exe 程序.yao      # 推荐：单文件，无依赖
> 爻语\解释器\exe\yao.exe 程序.yao        # 备选：开发时用，功能更全
> ```

> 但**不含** Web 服务、MQTT、Modbus TCP。做网页后端或工业物联请用 Python 版。

## 1. 第一句话

```yao
显("你好，爻语！")
```

`显` 是「显示」，即打印并换行。输出：

```
你好，爻语！
```

`显` 可以一次打印多个值，用空格分隔：

```yao
显("一加一等于", 1 + 1)
显("七除以二等于", 7 / 2)
显("真假与空：", 真, 假, 空)
```

```
一加一等于 2
七除以二等于 3.5
真假与空： 真 假 空
```

> 注：`/` 是真除，结果是浮点，但**显示时去掉多余尾零**——`100 / 10 / 2` 打印 `5` 而不是 `5.0`。
> 要整除用内置 `除(甲, 乙)`，它是向下取整：`除(-7, 2)` == `-4`。

## 2. 值写在左边

这是爻语之所以「非主流」的第一件事。主流语言：

```python
x = 42          # Python：先名字，后值
```

爻语把值放前面：

```yao
42 名 答案        注 「名」：新建绑定
43 易 答案        注 「易」：重新赋值
显(答案)          注 输出 43
```

为什么？因为爻语里「表达式在前」是统一规则：你总是先算出一个值，再决定它叫什么。

`名` 建立的绑定可以在同一作用域重复绑定（后者覆盖），但只能通过 `易` 修改：

```yao
1 名 甲
2 名 甲       注 允许：重新绑定
3 易 甲       注 允许：改已存在的绑定
显(甲)        注 3
```

对**尚未绑定过**的名字用 `易` 会报错：

```yao
试 【
  4 易 不存在
】 捕 误 【
  显(误["类"], 误["文"])    注 名误 第 1 行 第 3 列：名误：无法赋值：没有此名字「不存在」…
】
```

## 4. 数据类型

| 类型 | 写法 | 例子 |
|---|---|---|
| 数 | 整数或小数 | `42`、`3.14`、`-7`、`1.5e3` |
| 字 | 双引号或单引号 | `"你好"`、`'abc'`、`"换行\n"` |
| 真/假 | `真`、`假` | `真` |
| 空 | `空` | `空` |
| 列 | ASCII 方括号 | `[1, 2, 3]`、`[]` |
| 表 | 花括号 + `⇒` | `{ "甲" ⇒ 1, "乙" ⇒ 2 }` |

用 `型(值)` 看类型名：

```yao
显(型(42), 型("字"), 型(真), 型(空), 型([]), 型({}))
注 数 字 真 空 列 表
```

字符串支持转义：`\n` 换行、`\t` 制表、`\"` 引号、`\\` 反斜杠、`\u4e2d` 这类 Unicode 转义。

## 5. 运算

```yao
显(1 + 2 * 3)       注 7  —— 优先级与数学一致
显(10 - 2 - 3)      注 5  —— 左结合
显(2 ^ 10)          注 1024
显(2 ^ 3 ^ 2)       注 512  —— 幂是右结合
显(-2 ^ 2)          注 -4   —— 负号比幂低
显("甲" + "乙")      注 甲乙
显([1, 2] + [3])    注 [1, 2, 3]
显(7 % 3)           注 1
显(除(7, 2))         注 3
```

比较与逻辑：

```yao
显(1 == 1.0)        注 真 —— 数之间跨 int/float 相等
显("甲" != "乙")     注 真
显(非 真)            注 假
显(真 且 假)          注 假
显(真 或 假)          注 真
显(非 1 == 2)        注 真 —— 「非」作用于整个比较
```

## 6. 分支：只有「判」

爻语没有 `if`/`else`，统一用 `判`。

### 6.1 条件分支

```yao
85 名 分数

判 【
  分数 >= 90 ⇒ 显("优")
  分数 >= 60 ⇒ 显("及格")
  它 ⇒ 显("不及格")
】
```

臂体可以是单条语句，也可以是一个块：

```yao
85 名 分数

判 【
  分数 >= 90 ⇒ 【
    述("优秀")
    显("继续保持")
  】
  它 ⇒ 显("再努力")
】
```

真值规则（`判 【 条件 ⇒ … 】` 与 `循` 都用它）：

- **假**：`假`、`空`、`0`、`0.0`、`""`、`[]`、`{}`
- **真**：其余一切（包括非零数、非空字、非空列/表）

### 6.2 值匹配

`判` 后面跟一个值时，按**相等**比对每个臂：

```yao
"乙" 名 等级

判 等级 【
  "甲" ⇒ 显("最好")
  "乙" ⇒ 显("很好")
  "丙" ⇒ 显("合格")
  它 ⇒ 显("未知")
】
```

两种形态不能混用：带值就是匹配，不带值就是条件。

## 7. 循环

### 7.1 计数循环 `环 … 自 … 至 … 步`

```yao
环 i 自 0 至 5 【
  显("i =", i)
】
注 输出 0 1 2 3 4 —— 「至」不含终点

环 j 自 10 至 0 步 -2 【
  显(j)
】
注 输出 10 8 6 4 2
```

### 7.2 遍历 `遍 … 于 …`

列：拿到元素

```yao
遍 项 于 [10, 20, 30] 【
  显(项)
】
```

需要下标时写两个名字，先序后值：

```yao
遍 序, 项 于 ["甲", "乙"] 【
  显(序, 项)
】
注 0 甲 / 1 乙
```

表：拿到键值对

```yao
遍 键, 值 于 { "甲" ⇒ 1, "乙" ⇒ 2 } 【
  显(键, "=", 值)
】
```

字：遍历每个字符

```yao
遍 字 于 "爻语" 【
  显(字)
】
```

### 7.3 条件循环 `循`

```yao
0 名 计数
循 计数 < 3 【
  显(计数)
  计数 + 1 易 计数
】
```

### 7.4 `断` 与 `续`

```yao
环 i 自 0 至 10 【
  判 【
    i == 5 ⇒ 断
    i % 2 == 0 ⇒ 续
    它 ⇒ 显(i)
  】
】
注 输出 1 3（到 5 就跳出，偶数跳过）
```

## 8. 函数

### 8.1 具名函数用 `匠`

```yao
匠 加(甲, 乙) 【
  归 甲 + 乙
】

显(加(2, 3))     注 5
```

没有 `归` 时返回 `空`：

```yao
匠 说(话) 【
  显(话)
】
显(说("嗨"))      注 嗨 / 空
```

### 8.2 匿名函数：`(参) ⇒ 表达式` 或 `节 (参) 【 … 】`

```yao
2 名 双
(双)(21)         注 不是这样用

映([1, 2, 3], (x) ⇒ x * 2) ▷ 显      注 [2, 4, 6]
映([1, 2, 3], 节 (x) 【 归 x + 1 】) ▷ 显 注 [2, 3, 4]
```

### 8.3 闭包

函数会记住它定义时所在的作用域：

```yao
匠 计器() 【
  0 名 n
  归 节 () 【
    n + 1 易 n
    归 n
  】
】

计器() 名 计
显(计(), 计(), 计())     注 1 2 3
```

### 8.4 递归

```yao
匠 斐(数) 【
  判 【
    数 <= 1 ⇒ 归 数
    它 ⇒ 归 斐(数 - 1) + 斐(数 - 2)
  】
】
显(斐(10))       注 55
```

## 9. 集合操作

### 9.1 列

```yao
[3, 1, 2] 名 列一

显(长(列一))           注 3
显(列一[0], 列一[-1])   注 3 2  —— 负索引从尾部数
列一[1:3] 名 片
显(片)                 注 [1, 2]
显(含(列一, 2))        注 真
增(列一, 4)
显(列一)               注 [3, 1, 2, 4]
显(删(列一, 0))        注 3（被删的元素）
显(排([3, 1, 2]))      注 [1, 2, 3]
显(排(["乙", "甲"]))    注 按 Unicode 码位
```

### 9.2 表

```yao
{ "甲" ⇒ 1 } 名 表一

2 易 表一["乙"]          注 下标赋值，不存在则新建
显(表一["甲"])          注 1
显(表一.甲)             注 1，等价于 表一["甲"]
显(取(表一, "丙", 0))    注 0，带默认值
显(键集(表一))          注 [甲, 乙]
显(含(表一, "乙"))       注 真
显(删(表一, "乙"))       注 真
置(表一, "丙", 3)       注 写入并返回表本身
```

### 9.3 高阶函数

```yao
[1, 2, 3, 4] ▷ 映((x) ⇒ x * x) ▷ 显             注 [1, 4, 9, 16]
[1, 2, 3, 4] ▷ 筛((x) ⇒ x % 2 == 0) ▷ 显        注 [2, 4]
折([1, 2, 3], (累, 项) ⇒ 累 + 项, 0) ▷ 显         注 6
排(["甲乙", "丙"], 长) ▷ 显                       注 [丙, 甲乙]

注 管道 ▷：x ▷ f 等价 f(x)；x ▷ f(a) 等价 f(x, a)
5 ▷ 串 ▷ 显
```

## 10. 错误处理

```yao
试 【
  1 / 0
】 捕 误 【
  显("出错了：", 误["类"])
  显("位置：第", 误["行"], "行 第", 误["列"], "列")
  显("说明：", 误["文"])
】 终 【
  显("无论如何都会执行")
】
```

`误` 是表，字段：`类`（错误类别）、`文`（完整中文报错）、`行`、`列`、`栈`（调用栈列）。

主动抛错：

```yao
匠 校验(年) 【
  判 【
    年 < 0 ⇒ 抛 "年份不能为负"
    它 ⇒ 空
  】
】

试 【
  校验(-1)
】 捕 误 【
  显(误["文"])       注 第 N 行 第 M 列：抛误：年份不能为负
】
```

错误类别：`词误`、`法误`、`名误`、`型误`、`值误`、`零误`、`键误`、`核误`、`抛误`、`引误`、`网误`、`时误`、`限误`、`内误`。

## 11. 模块

`工具.yao`（与 `主.yao` 放在同一目录）：

```yao
匠 加(甲, 乙) 【 归 甲 + 乙 】
匠 减(甲, 乙) 【 归 甲 - 乙 】
"工具模块" 名 说明
```

`主.yao`：

```yao
引 "工具.yao" ⇒ 工具

显(工具["加"](2, 3))      注 5
显(工具["减"](9, 4))      注 5
显(工具["说明"])           注 工具模块
显(键集(工具))            注 [加, 减, 说明]
```

- 路径相对于**当前文件**所在目录；`.yao` 后缀可省。
- 模块只执行一次，结果缓存。
- 默认导出全部顶层绑定；写了 `出 加, 减` 就只导出列出的名字。

## 12. 文件与 JSON

```yao
写("build/输出.txt", "第一行\n第二行")
显(读("build/输出.txt"))
显(在("build/输出.txt"))      注 真

{ "甲" ⇒ 1, "列" ⇒ [1, 2] } ▷ 构 ▷ 显
注 {"甲": 1, "列": [1, 2]}

析("{\"乙\": null}") 名 数据
显(型(数据["乙"]))            注 空 —— JSON null 自动转成爻语「空」
```
