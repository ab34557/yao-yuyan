# 爻语内置函数手册

全部内置函数都在全局作用域，直接使用即可。共 **56 个**，另加一个全局请求对象 `请`。

> 约定：`→` 表示返回值。参数名里 `?` 表示可省略。所有出错都是中文 `爻误`，并在报错里给出行列。

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻语\解释器\exe\yao.exe 程序.yao      # 推荐：单文件，无依赖
> 爻语\解释器\exe\yao.exe 程序.yao        # 备选：开发时用，功能更全
> ```
>
> **能力差异**：`yao.exe`（C 版）支持语言核心语法、75 个内置函数里的 48 个，
> 但**不含** Web 服务、MQTT、Modbus TCP。做网页后端或工业物联请用 Python 版。
> 完整对照见 [手册.md](手册.md#解释器版本对照)。

## 一、输入输出与类型（6）

### `显(值…)`

打印（换行）。多个值之间用**一个空格**分隔，末尾换行。

```yao
显("甲", 1, 真, [1, 2], { "乙" ⇒ 2 })
注 甲 1 真 [1, 2] {乙 ⇒ 2}
```

展示规则（`显` 用爻语展示，区别于 `串`）：

| 值 | 展示 |
|---|---|
| 字 | 原样，不加引号 |
| 数 | 去尾零（`5.0` → `5`） |
| 真 / 假 | `真` / `假` |
| 空 | `空` |
| 列 | `[甲, 乙]`（元素递归用此规则） |
| 表 | `{甲 ⇒ 1, 乙 ⇒ 2}` |
| 匠 / 原生 | `匠 加(2 参)` / `内置 显` |
| 应 / 请 | `应(200)` / `请(GET /路径)` |

### `述(值…)`

同 `显`，但**不换行**。

```yao
述("第一段，")
述("第二段")
述("\n")
```

### `串(值) → 字`

转成字符串。**列与表返回 JSON 风格**（与 `显` 不同）：

```yao
显(串(42), 串(真), 串(空))
注 42 真 空

显(串([1, "甲"]))
注 [1, "甲"]

显(串({ "甲" ⇒ 1 }))
注 {"甲": 1}

显(串(5.0), 串(7 / 2))
注 5 3.5
```

### `数(值) → 数`

转成数。字会去首尾空白；`"42"` 得整数，`"3.5"` 得小数。

```yao
显(数("42") + 8)      注 50
显(数("3.5") * 2)     注 7
显(数(7))             注 7
```

出错：`数("abc")` → `型误：「abc」不是数字`；`数(真)` → `型误：真/假不能转成数`。

### `型(值) → 字`

返回类型名：`数`、`字`、`真`、`空`、`列`、`表`、`匠`、`应`、`请`。

```yao
显(型(42), 型("字"), 型(真), 型(空), 型([]), 型({}))
注 数 字 真 空 列 表
```

### `版本() → 字`

解释器版本号。

```yao
显(版本())    注 0.1.0
```

## 二、集合（19）

### `长(列/字/表) → 数`

```yao
显(长([1, 2, 3]), 长("爻语"), 长({ "甲" ⇒ 1 }))
注 3 2 1
```

### `切(列/字, 起, 止?) → 新值`

与切片语法 `[起:止]` 等价。省略 `止` 表示到末尾。

```yao
显(切([1, 2, 3, 4], 1, 3))    注 [2, 3]
显(切("爻语语言", 0, 2))       注 爻语
```

### `取(表/列, 键, 默认?) → 值`

取不到时返回默认值；**不给默认值时抛 `键误`**（列越界抛 `值误`）。

```yao
{ "甲" ⇒ 1 } 名 表一
显(取(表一, "甲"))          注 1
显(取(表一, "乙", 0))       注 0
显(取(表一, "乙", 空))      注 空
```

注意：`取(表, 键, 默认)` 判断的是「有没有给默认值」，所以给 `空` 也算给。

### `置(容器, 键, 值) → 容器`

写键并返回容器本身，适合管道。表不存在该键则新建；列按序替换。

```yao
{ } 名 表一
置(表一, "甲", 1)
表一 ▷ 置("乙", 2) ▷ 显
注 {甲 ⇒ 1, 乙 ⇒ 2}
```

### `含(容器, 值) → 真/假`

- 表：判断**键**是否存在
- 列：判断**元素**是否相等存在（深比较）
- 字：判断子串

```yao
显(含({ "甲" ⇒ 1 }, "甲"))   注 真
显(含([1, [2, 3]], [2, 3]))  注 真
显(含("爻语语言", "语言"))    注 真
```

### `增(列, 值) → 列`

原地追加，返回同一列。

```yao
[1] 名 列一
增(列一, 2)
显(列一)         注 [1, 2]
```

### `删(表, 键) → 真/假` / `删(列, 序) → 被删值`

```yao
{ "甲" ⇒ 1 } 名 表一
显(删(表一, "甲"))       注 真（删成功）
显(删(表一, "乙"))       注 假（本来就没有）

[10, 20, 30] 名 列一
显(删(列一, 0))          注 10
显(列一)                 注 [20, 30]
```

### `键集(表) → 列`

返回键的列（顺序为插入/赋值顺序）。

```yao
显(键集({ "甲" ⇒ 1, "乙" ⇒ 2 }))    注 [甲, 乙]
```

### `列(值) → 列`

字→字符列；表→键列；列→浅拷贝。

```yao
显(列("爻语"))                注 [爻, 语]
显(列({ "甲" ⇒ 1, "乙" ⇒ 2 })) 注 [甲, 乙]
```

### `映(列, 函数) → 新列`

对每个元素调用函数。

```yao
映([1, 2, 3], (x) ⇒ x * x) ▷ 显     注 [1, 4, 9]
映(["甲", "乙"], (s) ⇒ s + "!") ▷ 显 注 [甲!, 乙!]
```

### `筛(列, 函数) → 新列`

保留函数返回真值的元素。

```yao
筛([1, 2, 3, 4], (x) ⇒ x % 2 == 0) ▷ 显    注 [2, 4]
```

### `折(列, 函数, 初值) → 值`

函数签名为 `(累计, 项)`。

```yao
折([1, 2, 3, 4], (累, 项) ⇒ 累 + 项, 0) ▷ 显     注 10
折(["甲", "乙"], (累, 项) ⇒ 累 + "-" + 项, "") ▷ 显 注 -甲-乙
```

### `排(列, 键函数?) → 新列`

稳定排序，返回新列。默认按「数 < 字 < 其它」的顺序；字按 **Unicode 码位**（不是拼音）。

```yao
显(排([3, 1, 2]))             注 [1, 2, 3]
显(排(["丙", "甲"]))           注 [丙, 甲]（丙 U+4E19 < 甲 U+7532）
显(排(["甲乙", "丙"], 长))      注 [丙, 甲乙]（按长度）
显(排([{ "n" ⇒ 2 }, { "n" ⇒ 1 }], (x) ⇒ x["n"]))
注 [{n ⇒ 1}, {n ⇒ 2}]
```

### `复(列/字, 次数) → 新值`

```yao
显(复([1, 2], 3))     注 [1, 2, 1, 2, 1, 2]
显(复("哈", 3))       注 哈哈哈
```

数不支持 `复`（用乘法）。

### `并(列, 分隔?) → 字`

```yao
显(并(["甲", "乙", "丙"], "、"))    注 甲、乙、丙
显(并([1, 2, 3]))                   注 123
```

### `分(字, 分隔?) → 列`

不给分隔符时按任意空白拆分。

```yao
显(分("甲,乙,丙", ","))      注 [甲, 乙, 丙]
显(分("a  b   c"))           注 [a, b, c]
显(分("爻语", ""))            注 [爻, 语]
```

### `替(字, 旧, 新) → 字`

```yao
显(替("爻语很好用", "很好用", "真香"))    注 爻语真香
```

### `裁(字) → 字`

去掉首尾空白（含全角空格）。

```yao
显(裁("  爻语  "))    注 爻语
```

## 三、数学与杂项（10）

### `除(甲, 乙) → 数`

整除，**向下取整**（不是向零截断）。

```yao
显(除(7, 2), 除(-7, 2), 除(7, -2))
注 3 -4 -4
```

除以零 → `零误`。

### `绝(数) → 数`

```yao
显(绝(-3.5))     注 3.5
```

### `极(列, 键函数?) → 最大值`

```yao
显(极([3, 1, 2]))                 注 3
显(极([{ "n" ⇒ 1 }, { "n" ⇒ 5 }], (x) ⇒ x["n"]))
注 {n ⇒ 5}
```

空列 → `值误`。

### `下(列, 键函数?) → 最小值`

```yao
显(下([3, 1, 2]))     注 1
```

### `舍(数, 小数位?) → 数`

四舍五入（Python `round`，遇到 .5 时向偶数取整）。

```yao
显(舍(3.14159, 2))    注 3.14
显(舍(2.5), 舍(3.5))   注 2 4
```

### `随(下界, 上界) → 整数`

闭区间随机整数。

```yao
显(随(1, 6))      注 1 到 6 之间的整数
```

### `今() → 字`

当前本地时间，格式 `YYYY-MM-DD HH:MM:SS`。

```yao
显(今())     注 2026-10-20 01:23:45
```

### `眠(秒)`

休眠，0 到 600 秒。在线 IDE 里超过 5 秒会被判超时。

### `核(条件, 说明?) → 空`

条件为假时抛 `核误`，用于断言。

```yao
核(1 + 1 == 2)
试 【
  核(假, "这里应该为真")
】 捕 误 【
  显(误["类"])      注 核误
】
```

### `停(码?) → 立即退出`

退出码默认 0。在线 IDE 沙箱中禁用。

## 四、序列化 / 文件 / 环境（7）

### `析(字) → 值`

解析 JSON。**`null` 转成爻语 `空`**，嵌套也递归转换。

```yao
析("{\"甲\": null, \"乙\": [1, 2]}") 名 数据
显(型(数据["甲"]))         注 空
显(数据["甲"] == 空)       注 真
显(数据["乙"])             注 [1, 2]
```

解析失败 → `值误：JSON 解析失败：…`

### `构(值, 缩进?) → 字`

序列化为 JSON，中文不转义。`缩进` 给整数则美化。

```yao
显(构({ "甲" ⇒ 1 }))          注 {"甲": 1}

构([1, "甲"], 2) 名 美化
显(美化)
注【
输出带缩进：
[
  1,
  "甲"
]
】
```

空 → `null`；匠/应等不可序列化类型 → `型误`。

### `读(路径) → 字`

按 UTF-8 读文件。失败 → `值误`。在线 IDE 沙箱中禁用。

### `写(路径, 字) → 空`

按 UTF-8 写文件，**自动创建父目录**，换行统一为 `\n`。在线 IDE 沙箱中禁用。

```yao
写("build/演示/输出.txt", "第一行\n第二行")
显(读("build/演示/输出.txt"))
```

### `在(路径) → 真/假`

路径是否存在。在线 IDE 沙箱中禁用。

### `参() → 列`

命令行参数（**不含脚本文件名**）。

```powershell
爻语\解释器\exe\yao.exe 跑 脚本.yao 甲 乙
```

```yao
显(参())       注 [甲, 乙]
```

### `境(名) → 字/空`

读环境变量，不存在返回 `空`。

```yao
显(境("爻_端口"))     注 环境变量不存在时为 空
```

## 五、测试与分析（6）

这一组专为「写自动化测试 / 做性能与覆盖率分析」准备，`爻语/示例/测试台/` 就是它们的实战用法。

### `滴() → 数`

高精度计时起点（秒，浮点，来自 `time.perf_counter`）。

### `毫秒(起) → 数` / `毫秒(起, 止) → 数`

算耗时毫秒数，保留 3 位小数。只给起点时算到「现在」。

```yao
滴() 名 起
环 i 自 0 至 10000 【 空 】
显("耗时", 毫秒(起), "毫秒")

滴() 名 甲
滴() 名 乙
显("区间", 毫秒(甲, 乙), "毫秒")
```

### `开覆盖() → 空`

开启**函数级覆盖率追踪**。此后每次爻语函数被调用，都会记一次「签名 → 次数」。
签名格式为 `文件名:定义行:函数名`。

### `取覆盖() → 表`

取覆盖率快照：

| 键 | 说明 |
|---|---|
| `调用` | 表：签名 → 调用次数 |
| `行` | 表：签名 → 函数定义行号 |
| `已覆盖函数数` | 被调用过的函数个数 |
| `总调用次数` | 累计调用次数 |

```yao
匠 加(甲, 乙) 【 归 甲 + 乙 】
匠 减(甲, 乙) 【 归 甲 - 乙 】

开覆盖()
加(1, 2)
减(5, 3)
取覆盖() 名 报
显(报["已覆盖函数数"], 报["总调用次数"])
关覆盖()
```

### `关覆盖() → 空`

关闭追踪（追踪默认关闭，不影响正常运行性能）。

### `载模块(路径) → 表`

按路径加载 `.yao` 模块，返回它的导出表。解析顺序：绝对路径 → 进程工作目录 → 当前脚本所在目录。
写测试时用它加载被测文件：

```yao
载模块("爻语/示例/测试台/样例/账务.yao") 名 账
显(账["加"](2, 3))       注 5
```

> `载模块` 在在线 IDE 沙箱里禁用。

## 六、账号与安全（3）

做登录注册、会话令牌、密码存储的基础件。**绝不要把密码明文存进文件**——用这三个。

### `散列(文, 盐?) → 字`

加盐 SHA-256，返回 64 位十六进制摘要。同样的「文 + 盐」永远得到同一摘要，
但盐不同则摘要完全不同，所以攻击者无法用彩虹表反查。

```yao
注 注册时：生成随机盐，存下盐和「密码+盐」的摘要
随机字(16) 名 盐
散列("用户的密码", 盐) 名 摘要

注 登录时：用同样的盐重算，比对摘要
恒等(散列("用户的密码", 盐), 摘要) 名 通过

显(长(摘要))                         注 64
显(通过)                             注 真
显(散列("用户的密码", "另一个盐") == 摘要)  注 假
```

校验密码时不要用 `==` 比字符串（有时序攻击风险），用 `恒等`。

### `随机字(长度?, 字符集?) → 字`

密码学安全随机字符串（`secrets` 模块）。默认 URL 安全字符集，适合会话令牌与盐。

```yao
显(长(随机字(32)))          注 32
显(随机字(40) != 随机字(40)) 注 真
显(长(随机字(8, "0123456789")))  注 8，纯数字
显(随机字(6, "ABC"))              注 只含 A/B/C
```

长度需在 1–256 之间，否则 `值误`。

### `恒等(甲, 乙) → 真/假`

**恒定时间**比较两个字符串（`hmac.compare_digest`），即使内容不同，比较耗时也基本一致，
避免通过响应时间猜出令牌或摘要。

```yao
显(恒等("甲", "甲"))      注 真
显(恒等("甲", "乙"))      注 假
```

## 七、HTTP 客户端（2）

用来**从爻语里访问别的网站**，是 `爻语/示例/网站测试/`（测试网站的网站）与
`爻语/示例/接口测试平台/` 的基础。

### `抓(网址, 超时?) → 表`

抓取一个网址。**永远不抛异常**——连不上、超时、4xx/5xx 都以返回值的 `码`/`错` 表达，方便测试系统统一处理。

```yao
注 抓取一个本地服务；服务没在跑也不会崩，码 会是 0、错 里有说明
抓("http://127.0.0.1:8788/api/事项") 名 r
显(型(r["码"]))      注 数
显(型(r["字节"]))    注 数
显(型(r["毫秒"]))    注 数
显(型(r["头"]))      注 表
```

| 键 | 类型 | 说明 |
|---|---|---|
| `码` | 数 | HTTP 状态码；连不上时为 `0` |
| `头` | 表 | 响应头，键为小写 |
| `文` | 字 | 响应体文本（按 Content-Type 的 charset 解码） |
| `字节` | 数 | 响应体字节数 |
| `毫秒` | 数 | 总耗时 |
| `址` | 字 | 实际请求地址 |
| `错` | 字/空 | 成功为空；失败为 `"URLError: ..."` 这类说明 |

网址里的**中文会自动百分号编码**（与浏览器一致），可以直接写 `抓("http://站点/api/健康")`。

### `请求(网址, 选项?) → 表`

发任意方法的请求。返回结构与 `抓` 相同，另有 `法` 字段。

`选项` 是表：

| 键 | 默认 | 说明 |
|---|---|---|
| `法` | `"GET"` | HTTP 方法 |
| `体` | 空 | 请求体；表/列自动 JSON 序列化并设 `Content-Type` |
| `头` | 空 | 请求头表 |
| `超时` | 10 | 秒 |

```yao
请求("http://127.0.0.1:8788/api/事项", {
  "法" ⇒ "POST",
  "体" ⇒ { "内容" ⇒ "爻语自动化测试" }
}) 名 r
显(r["码"])       注 200
析(r["文"]) 名 项
显(项["编号"])

请求("http://127.0.0.1:8788/api/事项/1", { "法" ⇒ "DELETE" }) 名 删
```

> 请求头只能是 ASCII。头名或头值含中文会得到中文 `型误`：
> `请求头值「X-说明」含非 ASCII 字符（HTTP 头必须用 ASCII，中文内容请放进请求体）`

`抓` 与 `请求` 都在在线 IDE 沙箱里禁用。

## 八、网页运行时（4 + 请求对象）

详见 [Web开发.md](Web开发.md)。这里列出签名。

| 内置 | 签名 | 说明 |
|---|---|---|
| `路` | `路(法, 径, 处理函数)` | 注册路由，径支持 `:名` 路径参数 |
| `共` | `共(目录, 前缀?)` | 注册静态目录，默认挂 `/公共/` |
| `应` | `应(码, 头?, 体?)` | 构造响应对象 |
| `听` | `听(端口?)` | 启动 HTTP 服务（阻塞）；无参时读环境变量 `爻_端口`，再默认 8788 |

`请` 是当前请求对象，字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `请.法` | 字 | `GET`/`POST`/… |
| `请.径` | 字 | 路径，如 `/事项/3` |
| `请.参` | 表 | 路径参数 + 查询参数合并 |
| `请.体` | 值 | JSON 自动解析成表/列；表单解析成表；其它为字 |
| `请.头` | 表 | 请求头，键小写 |
| `请.原` | 字 | 原始请求体字符串 |

> 请求路径里的中文需要百分号编码（HTTP 规范要求），浏览器与 `fetch` 会自动处理。

## 九、物联网（Modbus TCP / MQTT）

工业现场的两种主流协议。这两个模块用 Python 标准库从零实现（不依赖 pymodbus / paho-mqtt）。

### Modbus TCP（4 个）

Modbus 是工业 PLC / 变频器 / 传感器最常用的协议。上位机通过读写寄存器控制设备。

| 内置 | 签名 | 说明 |
|---|---|---|
| `读寄` | `读寄(主机, 端口, 单元, 起址, 个数, 超时?)` | 读保持寄存器，返回 `{成, 错, 值们}` |
| `写寄` | `写寄(主机, 端口, 单元, 地址, 值, 超时?)` | 写单个寄存器，返回 `{成, 错}` |
| `批量写` | `批量写(主机, 端口, 单元, 起址, 值们, 超时?)` | 连续写多个寄存器 |
| `探活` | `探活(主机, 端口, 超时?)` | 测 TCP 连通性，返回 `{成, 错}` |

```yao-fragment
注 读 16 个寄存器（地址 0..15）
注 读 16 个寄存器（地址 0..15）
读寄("127.0.0.1", 15020, 1, 0, 16) 名 果
判 取(果, "成", 假) 【
  真 ⇒ 【
    取(果, "值们", []) 名 值们
    显("速度 = ", 取(值们, 0, 0) / 100.0, " m/s")
  】
  它 ⇒ 显("读失败：", 取(果, "错", "未知"))
】

注 写调速寄存器（速度 × 100 存成整数）
写寄("127.0.0.1", 15020, 1, 0, 250) 名 写果
判 取(写果, "成", 假) 【
  真 ⇒ 显("已下发")
  它 ⇒ 显("失败：", 取(写果, "错", "未知"))
】
```

> **寄存器值只能是 0-65535 的整数。** 浮点要自己缩放（如速度 ×100 存成 230）。
> **注意截断问题**：`int(2.3 * 100)` 会得到 229（因为 2.3*100 = 229.9999…），
> 算寄存器值要用 `整(舍(值 * 100, 0))`。

### MQTT（5 个）

MQTT 是物联网上报数据的轻量协议（发布/订阅模型）。设备往主题发数据，上位机订阅后接收。

| 内置 | 签名 | 说明 |
|---|---|---|
| `联` | `联(主机, 端口, 客户端号, 超时?)` | 连接 Broker，返回 `{号, 错}`；`号` 为 0 表示失败 |
| `订` | `订(句柄, 主题)` | 订阅主题，返回 `{成, 错}` |
| `播` | `播(句柄, 主题, 内容)` | 发布消息（内容可以是字或表） |
| `收讯` | `收讯(句柄, 超时秒?)` | 收一条消息，返回 `{错, 超时, 内容, 主题}` |
| `离联` | `离联(句柄)` | 断开连接 |

```yao-fragment
联("127.0.0.1", 1883, "上位机-" + 随机字(6)) 名 连
判 连["号"] == 0 【
  真 ⇒ 显("连不上 MQTT：", 连["错"])
】

循 真 【
  收讯(连["号"], 2) 名 讯
  判 讯["错"] != "" 【
    真 ⇒ 断         注 任何错误都当作断线，跳出重连
  】
  判 讯["超时"] == 假 【
    真 ⇒ 【
      析(讯["内容"]) 名 遥
      显("收到：", 取(遥, "产出", 空))
    】
  】
】
离联(连["号"])
```

**三个坑**：

1. **`收讯` 的错误信息文案不固定**。对端被强杀时是 `接收失败：[WinError 10054] 远程主机强迫关闭…`，
   `离联` 后是别的字符串。**判断断线要看 `讯["错"] != ""`，不要精确匹配某个字符串**。
2. **`收讯` 会阻塞**。设短超时（1-3 秒）并在超时后检查停止标志，否则线程停不下来。
3. **`离联` 能让阻塞中的 `收讯` 立刻返回**。要停止采集线程，先 `离联`，再 `停采`。

## 十、TCP 与后台采集

| 内置 | 签名 | 说明 |
|---|---|---|
| `连` | `连(主机, 端口, 超时?)` | 建 TCP 连接，返回 `{号, 错}` |
| `发字` | `发字(句柄, 内容)` | 发送字符串（UTF-8） |
| `收字` | `收字(句柄, 超时?)` | 接收，返回 `{内容, 超时, 错}` |
| `断连` | `断连(句柄)` | 关闭连接 |
| `启采` | `启采(函数, 参们?)` | 起后台线程跑函数，返回 `{号, 错}` |
| `停采` | `停采(号)` | 停后台线程 |

`启采` 让长任务（如 MQTT 采集循环）跑在后台，不阻塞主线程：

```yao
假 名 应停采集
0 名 采集号

匠 采集循环() 【
  真 名 继续跑
  循 继续跑 【
    判 【 应停采集 ⇒ 假 易 继续跑 它 ⇒ 空 】
    眠(1)
  】
】

注 启动：先清标志，再起线程
假 易 应停采集
启采(采集循环) 名 结果
取(结果, "号", 0) 易 采集号

注 停止：先置标志，再等线程自己退出
真 易 应停采集
眠(2)
停采(采集号)
0 易 采集号
```

> **`停采` 不能强制杀死线程。** 如果线程卡在阻塞调用（如 `收讯`）里，
> `停采` 会一直等。正确做法是**先让阻塞调用返回**（`离联` / `断连`），
> 同时设一个停止标志让循环下一轮自己退出。

## 十一、字符与整数工具

| 内置 | 签名 | 说明 |
|---|---|---|
| `字码` | `字码(字, 位置?)` | 取某位置字符的码点（整数） |
| `码字` | `码字(整数)` | 码点转字符 |
| `整` | `整(值)` | 转整数（截断小数） |

写词法分析器 / 文本处理时需要按字符分类：

```yao
"abc123 你好" 名 文
0 名 i
循 i < 长(文) 【
  字码(文, i) 名 码
  判 【
    码 >= 48 且 码 <= 57 ⇒ 显("数字：", 取(文, i, ""))
    码 >= 97 且 码 <= 122 ⇒ 显("小写：", 取(文, i, ""))
    码 >= 19968 ⇒ 显("汉字：", 取(文, i, ""))
  】
  i + 1 易 i
】
```

> `取(字, 下标)` 可以按字符下标访问字符串，返回单字符。
> 注意 `整()` 是**截断**（`整(2.9)` = 2），四舍五入用 `舍(值, 0)`。
