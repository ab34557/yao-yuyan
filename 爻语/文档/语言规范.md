# 爻语语言规范 v0.1

本文档是爻语的**完整语言规格**。实现、测试、在线 IDE 高亮都以本文档为准；
`SPEC.md`（仓库根目录）是实现期的权威定义，两者如有出入以 `SPEC.md` 为准并请提 issue。

- 文件后缀：`.yao`
- 编码：UTF-8（BOM 会自动忽略）
- 换行：`\n` 或 `\r\n` 均可
- 解释器：`爻语\解释器\exe\yao.exe`，仅依赖 Python 3.10+ 标准库

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻语\解释器\exe\yao.exe 程序.yao      # 推荐：单文件，无依赖
> 爻语\解释器\exe\yao.exe 程序.yao        # 备选：开发时用，功能更全
> ```
>
> **能力差异**：`yao.exe`（C 版）支持语言核心语法、75 个内置函数里的 48 个，
> 但**不含** Web 服务、MQTT、Modbus TCP。做网页后端或工业物联请用 Python 版。
> 完整对照见 [手册.md](手册.md#解释器版本对照)。

## 1. 设计原则

1. **关键字全部为中文单字**，与 Python / JS / Java / Go / C 保留字集合交集为空。
2. **值在左**：绑定与赋值把值写在前面（`42 名 答案`）。
3. **块用 `【 】`**，不依赖缩进；`{ }` 只用于表字面量，`[ ]` 只用于索引与列表。
4. **分支统一为 `判`**，没有独立的 if/else/switch。
5. **一切报错为中文**，格式 `第 N 行 第 M 列：<类>：<说明>`。

## 2. 词法

### 2.1 源文件与分隔符

- 语句分隔：**换行**（在 `(`、`[`、`{` 括号深度为 0 时生效）或 **分号** `；` / `;`。
- 块内换行同样产生分隔符。
- 文件结尾自动结束最后一条语句。

### 2.2 注释

| 形式 | 示例 |
|---|---|
| 行注释 | `注 这是注释，到行尾` |
| 块注释 | `注【 … 】`，**可嵌套** |

```yao
注【
  外层
  注【 内层 】
  仍在注释里
】
显("注释之后")
```

### 2.3 标识符

```
首字符  := 汉字 | 字母 | "_"
后续    := 汉字 | 字母 | 数字 | "_"
```

- 汉字范围：U+4E00–U+9FFF、U+3400–U+4DBF、U+F900–U+FAFF。
- 标识符会做 NFKC 归一（全角字母 → 半角）。
- **关键字不能作标识符**。确有需要时用反引号：`` `名` ``、`` `真` ``。

### 2.4 字面量

| 类型 | 语法 | 示例 |
|---|---|---|
| 整数 | 十进制数字，可用 `_` 分隔 | `42`、`1_000_000` |
| 小数 | 含 `.` 或指数 | `3.14`、`1.5e3`、`.5` |
| 字 | `"…"`、`'…'`、`"…"`、`'…'` | `"你好"`、`'abc'` |
| 真 | `真` | |
| 假 | `假` | |
| 空 | `空` | |
| 列 | `[ 元素, … ]` | `[1, "甲", [2]]`、`[]` |
| 表 | `{ 键 ⇒ 值, … }` | `{ "甲" ⇒ 1 }`、`{}` |

字符串转义：`\n`、`\t`、`\r`、`\\`、`\"`、`\'`、`\0`、`\uXXXX`。

表的键必须可散列：字 / 数 / 真 / 假 / 空。

### 2.5 运算符与符号

| 语义 | 主形 | 别名 | 说明 |
|---|---|---|---|
| 管道 | `▷` | `\|>` | `x ▷ f` 等价 `f(x)` |
| 箭头 | `⇒` | `=>` | 绑定 / 分支臂 / 表键值 |
| 幂 | `^` | `**` | 右结合 |
| 语句分隔 | `；` | `;` | |
| 参数分隔 | `，` | `,` | |
| 块 | `【` `】` | — | |
| 索引/列表 | `[` `]` | — | ASCII |
| 表 | `{` `}` | — | ASCII |
| 成员 | `.` | — | |

括号也接受全角形式：`（）［］｛｝：。＝＋－＊／％＜＞！`。

### 2.6 关键字（29 个）

```
名 易 匠 节 归 判 它 遍 于 环 自 至 步 循 断 续
试 捕 终 抛 引 出 注 真 假 空 且 或 非
```

| 词 | 含义 | 词 | 含义 |
|---|---|---|---|
| `名` | 不可变绑定 | `易` | 重新赋值 |
| `匠` | 具名函数 | `节` | 匿名函数块 |
| `归` | 返回 | `判` | 分支 / 值匹配 |
| `它` | 兜底臂 | `遍` | 遍历 |
| `于` | 遍历来源 | `环` | 计数循环 |
| `自` | 计数起点 | `至` | 计数终点（不含） |
| `步` | 计数步长 | `循` | 条件循环 |
| `断` | 跳出 | `续` | 下一轮 |
| `试` | 保护块 | `捕` | 捕获 |
| `终` | 收尾块 | `抛` | 抛出 |
| `引` | 引入模块 | `出` | 显式导出 |
| `注` | 注释 | `真` `假` `空` | 常量 |
| `且` `或` `非` | 逻辑 | | |

## 3. 语法（EBNF）

```ebnf
程序        = 语句* ;
语句        = 绑定 | 赋值 | 函数定义 | 分支 | 遍历 | 计数循环
            | 条件循环 | 试捕 | 抛出 | 引入 | 导出 | 归 | 断 | 续
            | 无括号调用 | 表达式 ;

绑定        = 表达式 "名" 标识符 ;
赋值        = 表达式 "易" 目标 ;
目标        = 标识符 | 目标 "[" 表达式 "]" | 目标 "." 标识符 ;

函数定义    = "匠" 标识符 "(" 参数表? ")" 块 ;
参数表      = 标识符 ("," 标识符)* ;

分支        = "判" 表达式? 臂块 ;
臂块        = "【" 臂+ "】" ;
臂          = ( 表达式 | "它" ) "⇒" ( 语句 | 块 ) ;

遍历        = "遍" 标识符 ("," 标识符)? "于" 表达式 块 ;
计数循环    = "环" 标识符 "自" 表达式 "至" 表达式 ("步" 表达式)? 块 ;
条件循环    = "循" 表达式 块 ;

试捕        = "试" 块 ( "捕" 标识符? 块 )? ( "终" 块 )? ;
抛出        = "抛" 表达式 ;
引入        = "引" 表达式 ( "⇒" 标识符 )? ;
导出        = "出" 标识符 ("," 标识符)* ;
归          = "归" 表达式? ;
断          = "断" ;
续          = "续" ;

无括号调用  = 可调用表达式 表达式+ ;          (* 仅语句位置 *)
块          = "【" 语句* "】" ;

表达式      = 或表达式 ;
或表达式    = 且表达式 ( "或" 且表达式 )* ;
且表达式    = 非表达式 ( "且" 非表达式 )* ;
非表达式    = "非" 非表达式 | 比较表达式 ;
比较表达式  = 管道表达式 ( ("==" | "!=" | "<" | "<=" | ">" | ">=") 管道表达式 )* ;
管道表达式  = 加减表达式 ( "▷" 加减表达式 )* ;
加减表达式  = 乘除表达式 ( ("+" | "-") 乘除表达式 )* ;
乘除表达式  = 一元表达式 ( ("*" | "/" | "%") 一元表达式 )* ;
一元表达式  = "-" 一元表达式 | "+" 一元表达式 | 幂表达式 ;
幂表达式    = 后缀表达式 ( "^" 一元表达式 )? ;          (* 右结合 *)
后缀表达式  = 原子 ( "(" 实参表? ")" | "[" 下标 "]" | "." 标识符 )* ;
下标        = 表达式 | 表达式? ":" 表达式? ;
原子        = 数 | 字 | 真 | 假 | 空 | 标识符
            | 列字面量 | 表字面量
            | "(" 表达式 ")"
            | "(" 参数表 ")" "⇒" 表达式
            | "节" "(" 参数表? ")" 块 ;
列字面量    = "[" ( 表达式 ("," 表达式)* )? "]" ;
表字面量    = "{" ( 表达式 "⇒" 表达式 ("," 表达式 "⇒" 表达式)* )? "}" ;
```

## 4. 表达式语义

### 4.1 优先级（低 → 高）

| 级 | 运算 | 结合 |
|---|---|---|
| 1 | `或` | 左 |
| 2 | `且` | 左 |
| 3 | `非`（前缀） | — |
| 4 | `== != < <= > >=` | 左 |
| 5 | `▷` | 左 |
| 6 | `+ -` | 左 |
| 7 | `* / %` | 左 |
| 8 | 一元 `-` `+` | — |
| 9 | `^` | **右** |
| 10 | `()` `[]` `.` | 左 |

```yao
显(1 + 2 * 3)       注 7
显(2 ^ 3 ^ 2)       注 512
显(-2 ^ 2)          注 -4
显(非 1 == 2)        注 真（等价 非 (1 == 2)）
显(100 / 10 / 2)    注 5（真除 5.0，显示去尾零）
```

### 4.2 算术

| 运算 | 规则 |
|---|---|
| `+` | 字+字 拼接；列+列 连接；字与其它 自动转字拼接；数+数 求和 |
| `-` `*` `/` `%` | 数运算；`*` 额外支持 字×整数、列×整数 |
| `/` | 真除，结果浮点；除以零 → `零误` |
| `^` | 幂，右结合；负指数得浮点 |
| `%` | 取余 |

### 4.3 比较与相等

- `==` / `!=`：见 4.4 相等规则。
- `< <= > >=`：仅支持 数 与 数、字 与 字；其它 → `型误`。
- 不支持链式比较（`a < b < c` 会被解析成 `(a < b) < c` 并报 `型误`）。

### 4.4 相等规则

| 甲 | 乙 | 结果 |
|---|---|---|
| 数 | 数 | 数值相等（`1 == 1.0` 真） |
| 字 | 字 | 内容相等 |
| 真/假 | 同值布尔 | 真 |
| 真/假 | 数 | **恒假**（不抛错） |
| 空 | 空 | 真 |
| 空 | 其它 | 假 |
| 列 | 列 | 长度相同且逐项相等（深比较） |
| 表 | 表 | 键集相同且逐键值相等 |
| 不同类 | | 恒假 |

### 4.5 真值规则

**假**：`假`、`空`、`0`、`0.0`、`""`、`[]`、`{}`
**真**：其余一切（非零数、非空字/列/表、匠、应、请…）

### 4.6 管道

`x ▷ f` 等价 `f(x)`；`x ▷ f(a)` 等价 `f(x, a)`；`x ▷ g ▷ h` 等价 `h(g(x))`。

```yao
" 爻语 " ▷ 裁 ▷ 显
[1, 2, 3] ▷ 映((x) ⇒ x * 2) ▷ 筛((x) ⇒ x > 2) ▷ 显
```

### 4.7 索引、切片、成员

```yao
[10, 20, 30, 40] 名 列
"爻语" 名 字

显(列[0])        注 10 —— 取元素
显(列[-1])       注 40 —— 负索引从尾部数
显(列[1:3])      注 [20, 30] —— 切片
显(列[:2])       注 [10, 20]
显(列[2:])       注 [30, 40]
显(列[:])        注 [10, 20, 30, 40]
显(字[0])        注 爻 —— 取单个字符

{ "键" ⇒ 1 } 名 表
显(表["键"])     注 1 —— 键不存在 → 键误
显(表.键)        注 1 —— 等价 表["键"]
```

越界 → `值误`；键不存在 → `键误`；类型不对 → `型误`。

### 4.8 成员调用（对象模型）

```yao
{ "值" ⇒ 10, "取" ⇒ 节 (我) 【 归 我["值"] 】 } 名 点
显(点.取())       注 10 —— 点 被作为第一个参数注入
```

规则：`对象.方法(参)` 中若 `对象` 是表且该键是函数，则等价于 `方法(对象, 参)`。

## 5. 语句语义

### 5.1 绑定 `名` 与赋值 `易`

```yao
42 名 答案          注 在当前作用域新建绑定
43 易 答案          注 沿作用域链向上找，必须已存在

{ } 名 表一
1 易 表一["甲"]      注 下标赋值，键不存在则新建
2 易 表一.乙         注 成员赋值（表）
```

- `名` 的右侧只能是**名字**；不能写 `42 名 表["甲"]`。
- `易` 的目标可以是 名字 / 索引 / 成员。
- 对不存在的名字用 `易` → `名误`。

### 5.2 分支 `判`

- 带被匹配值：逐臂做**相等比较**，命中即执行，`它` 兜底。
- 不带被匹配值：逐臂把模式当**条件**按真值规则判断。
- 全部未命中且无 `它` → 结果为 `空`。
- 臂体可以是单条语句或一个块。

### 5.3 循环

| 语句 | 语义 |
|---|---|
| `环 i 自 起 至 止 步 步长 块` | `i` 从 `起` 开始，**不含** `止`；步长为负时递减；步长 0 → `值误` |
| `遍 项 于 列 块` | 遍历元素 |
| `遍 序, 项 于 列 块` | 同时给下标 |
| `遍 键, 值 于 表 块` | 遍历键值对 |
| `遍 字 于 字符串 块` | 遍历字符 |
| `循 条件 块` | 条件为真时循环 |

`断` 跳出当前循环；`续` 进入下一轮。每轮循环变量在新作用域中，轮次间不共享。

循环外使用 `断`/`续` → `法误`。

### 5.4 异常 `试 / 捕 / 终`

```yao
试 【
  1 / 0
】 捕 误 【
  显("类：", 误["类"])
  显("文：", 误["文"])
  显("位置：", 误["行"], 误["列"])
  显("栈：", 误["栈"])
】 终 【
  显("无论如何都执行")
】
```

- `捕` 与 `终` 至少有一个。
- 错误对象是表：`类`、`文`、`行`、`列`、`栈`。
- `捕` 只捕获爻语错误（`爻误` 及其子类）；`断`/`续`/`归` 不是错误，不被捕获。
- `终` 一定执行，包括捕体里再次抛错。

### 5.5 抛出 `抛`

抛出 `抛` 的三种写法：

```yao
试 【
  抛 "说明文字"
】 捕 误 【
  显(误["类"])       注 抛误
】

试 【
  抛 { "类" ⇒ "值误", "文" ⇒ "自定义说明" }
】 捕 误 【
  显(误["类"], 误["文"])
】
```

### 5.6 模块 `引` / `出`

```yao
注 工具.yao 内容：
注   匠 加(甲, 乙) 【 归 甲 + 乙 】
注   "工具模块" 名 说明

引 "工具.yao" ⇒ 工具       注 相对当前文件目录；后缀可省
显(工具["加"](2, 3))
显(工具["说明"])
```

- 模块顶层执行**一次**，结果缓存（同进程内）。
- 结果是表：键为导出名。
- 默认导出全部顶层绑定；模块中一旦出现 `出`，则只导出列出的名字。
- 循环引入 → `引误`。
- 内置函数不会被导出（模块只能导出自己定义的绑定）。

## 6. 作用域与闭包

- 顶层、每个块 `【 】`、每个函数体都是新作用域。
- `名` 在当前作用域新建绑定；`易` 沿作用域链向上查找。
- 函数捕获**定义处**的作用域（闭包）。
- 模块有独立的根作用域，其父为全局（可见内置），但导出只看模块自身。

```yao
匠 计器() 【
  0 名 n
  归 节 () 【
    n + 1 易 n
    归 n
  】
】
计器() 名 计
显(计(), 计(), 计())     注 1 2 3
```

## 7. 无括号调用（语句级语法糖）

在**语句位置**，`可调用 实参 实参 …` 等价于 `可调用(实参, 实参, …)`：

```yao
显 "你好" "世界"

[1] 名 列表
增(列表, 2)          注 传变量必须写括号，不能写 `增 列表 2`
显(列表)             注 [1, 2]

共 "爻语/示例/待办/公共"

路 "GET" "/x" 节 (请) 【 归 请.径 】
```

限制：
- 仅在语句开头生效；表达式中必须写括号。
- **实参必须自明**：字面量、列/表字面量、括号表达式、`节 (…) 【…】`、箭头函数。
  裸标识符不行——`甲 乙 丙` 与「三条相邻语句」无法区分，所以传变量一律写 `f(变量)`。
- `名`/`易` 语句优先于无括号调用。

限制：仅在语句开头生效；表达式中必须写括号；`名`/`易` 语句优先。

## 8. 错误体系

### 8.1 类别

| 类 | 触发场景 |
|---|---|
| `词误` | 非法字符、字符串/注释/反引号未闭合、非法数字 |
| `法误` | 语法结构错误、`断`/`续`/`归` 用错位置 |
| `名误` | 名字不存在、对未绑定名字赋值 |
| `型误` | 类型不匹配、调用非函数、参数个数不符 |
| `值误` | 索引越界、非法值、JSON 解析失败、空列取极值 |
| `零误` | 除以零 / 对零取余 |
| `键误` | 表里没有该键 |
| `核误` | `核()` 断言失败 |
| `抛误` | 用户 `抛` |
| `引误` | 模块找不到 / 循环引入 |
| `网误` | 网页运行时错误（端口占用、非法响应头等） |
| `时误` | 在线 IDE 执行超时 |
| `限误` | 步数/输出超限 |
| `内误` | 解释器内部错误 |

### 8.2 报错格式

```
第 3 行 第 5 列：名误：没有此名字「甲」
  在 匠 算账(主.yao:12) 调用处
```

- 首行：`第 N 行 第 M 列：<类>：<说明>`
- 其后每行缩进两格，是调用栈（由内向外）。

### 8.3 退出码

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 语言错误（爻误） |
| 2 | 用法错误（文件不存在、端口参数非法等） |

## 9. 数值与显示

- 整数任意精度；小数 IEEE 754 双精度。
- `/` 结果浮点，**显示时去掉多余尾零**：`5.0` → `5`，`3.5` → `3.5`。
- `串()` 与 `显()` 对**列/表**的表现不同：
  - `显([1, "甲"])` → `[1, 甲]`（爻语展示）
  - `串([1, "甲"])` → `[1, "甲"]`（JSON 风格）

| 绑定 | `42 名 x` | `x = 42` | `const x = 42` |
| 重赋值 | `43 易 x` | `x = 43` | `x = 43` |
| 函数 | `匠 f(a) 【 归 a 】` | `def f(a): return a` | `function f(a){return a}` |
| 匿名函数 | `(a) ⇒ a * 2` | `lambda a: a*2` | `a => a*2` |
| 条件 | `判 【 c ⇒ … 它 ⇒ … 】` | `if c: … else: …` | `if (c) {…} else {…}` |
| 多路分支 | `判 v 【 1 ⇒ … 】` | `match v:` | `switch (v)` |
| 遍历 | `遍 x 于 列 【 … 】` | `for x in 列:` | `for (const x of 列)` |
| 计数循环 | `环 i 自 0 至 10 【 … 】` | `for i in range(10):` | `for (let i=0;i<10;i++)` |
| 条件循环 | `循 c 【 … 】` | `while c:` | `while (c)` |
| 异常 | `试 捕 终` | `try/except/finally` | `try/catch/finally` |
| 模块 | `引 "a.yao" ⇒ a` | `import a` | `import a from './a.js'` |
| 管道 | `x ▷ f` | 无（需嵌套） | 提案中的 `|>` |
| 块 | `【 】` | 缩进 | `{ }` |

## 11. 实现约束

- 解释执行（树遍历），无编译步骤，无字节码缓存。
- 递归深度受 Python 栈限制（默认约 1000 层）。
- 仅标准库，无第三方依赖。
- 未实现：类与继承、泛型、宏、运算符重载、并发原语、包管理。
  对象用「表 + 匠」+ 成员调用注入接收者来模拟。
