# 爻语（Yao）语言手册

> 一门用 Python 实现的通用编程语言。关键字全部是**单字汉字**，与 Python / JavaScript /
> Java / Go / C 的关键字**零重合**；变量绑定采用**值在左**的写法。
>
> 版本 0.1.0 ｜ 文件后缀 `.yao` ｜ 实现：Python 3.11 标准库 ｜ 入口 `爻语\解释器\exe\yao.exe`

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻语\解释器\exe\yao.exe 程序.yao      # 推荐：单文件，无依赖
> 爻语\解释器\exe\yao.exe 程序.yao        # 备选：开发时用，功能更全
> ```
>
> **能力差异**：`yao.exe`（C 版）支持语言核心语法、75 个内置函数里的 48 个，
> 但**不含** Web 服务、MQTT、Modbus TCP。做网页后端或工业物联请用 Python 版。
> 完整对照见 [手册.md](手册.md#解释器版本对照)。

## 1. 它是什么

爻语是一门**图灵完备的通用语言**，能写脚本、写命令行工具，也能写 Web 后端
（内置 HTTP 服务器、路由、请求/响应处理）。

设计上做了三个刻意的选择：

| 选择 | 具体做法 | 代价 |
|---|---|---|
| **关键字不用英文** | 29 个关键字全是单字汉字：`名 易 匠 归 判 …` | 需要中文输入法 |
| **值在左边** | `42 名 答案` 表示「把 42 取名为 答案」 | 初次接触会觉得顺序反了 |
| **块用括号不用缩进** | `【 … 】` | 比缩进多打两个字符 |

它不是玩具：爻语本身能写完整的 Web 应用（本仓库的论坛、接口测试平台都是爻语写的）。

> 注意：爻语是**后端语言**。它只负责逻辑与数据，产出的是 JSON 而不是 HTML ——
> 界面由它的姊妹语言 [爻页（YaoPage）](../爻页/手册.md) 描述，
> 两者之间用 JSON over HTTP 通信，全程不涉及 HTML / CSS / JavaScript。

## 2. 安装与运行

### 环境

- Python **3.11+**
- 只用标准库，**无需 pip install**

### 三种运行方式

```powershell
# 1. 跑一个文件
爻语\解释器\exe\yao.exe 跑 程序.yao

# 2. 直接执行（.yao 文件里第一行写 #! 也行）
python -X utf8 程序.yao

# 3. 交互式 REPL
爻语\解释器\exe\yao.exe
```

> Windows 上务必加 `-X utf8`，否则中文输出可能乱码。

### 全部子命令

| 命令 | 作用 |
|---|---|
| `爻语\解释器\exe\yao.exe` | 进入交互式 REPL |
| `爻语\解释器\exe\yao.exe 文件.yao` | 运行文件 |
| `爻语\解释器\exe\yao.exe --check 文件.yao` | 只做词法 + 语法检查（不执行） |
| `爻语\解释器\exe\yao.exe 版` | 打印版本 |
| `爻语\解释器\exe\yao.exe 站 端口` | 启动在线 IDE |

编辑器的源码在 [爻语/解释器/python版/](爻语/解释器/python版/)，每个文件职责单一：

```
爻语/解释器/python版/
├─ tokens.py       关键字表、符号别名
├─ lexer.py        词法分析
├─ parser.py       语法分析（递归下降 + Pratt）
├─ ast_nodes.py    抽象语法树节点
├─ interpreter.py  树遍历解释器
├─ env.py          作用域
├─ values.py       值类型与运算
├─ builtins.py     内置函数
├─ errors.py       错误类型
├─ web.py          HTTP 服务器与路由
├─ cli.py          命令行
└─ ide_server.py   在线 IDE
```

## 3. 第一个程序

```
注 这是注释。注 后面必须跟空格
显("你好，爻语")

42 名 答案
显(答案 * 2)          注 输出 84
```

运行：

```powershell
爻语\解释器\exe\yao.exe 跑 你好.yao
```

输出：

```
你好，爻语

```

**注意 `42 名 答案` 的顺序**：先写值，再写 `名`，最后写名字。
读作「42，命名为，答案」。

## 4. 词法

### 4.1 注释

```
注 单行注释，到行尾结束
注【 块注释
     可以嵌套 注【 里面还有一层 】 结束
】
```

`注` 后面必须跟**空格 / 制表 / 换行 / 行尾 / `【`**，否则它属于标识符的一部分
（所以 `注册`、`注意` 可以作变量名）。

### 4.2 标识符

- 首字符：汉字、英文字母、`_`
- 后续：再加数字
- **不能**与关键字同名，也**不能以关键字字符结尾**

```
甲 名 值        注 ✓
user1 名 值     注 ✓
用户名 名 值     注 ✗ 「用户名」以关键字「名」结尾
用 名 户名      注 ✓ 换一种写法
```

### 4.3 字面量

| 类型 | 写法 |
|---|---|
| 整数 | `42`、`-7` |
| 小数 | `3.14`、`0.5` |
| 字符串 | `"双引号"`、`'单引号'`、`「中文引号也行」` |
| 布尔 | `真`、`假` |
| 空 | `空` |
| 列表 | `[1, 2, 3]` |
| 表（字典） | `{ "键" ⇒ 值 }` |

字符串转义：`\n` `\t` `\"` `\\`。

### 4.4 符号双写

爻语接受全角和半角两套符号，习惯哪种用哪种：

| 中文 | 半角 |
|---|---|
| `（ ）` | `( )` |
| `【 】` | 无（块必须用中文方括号） |
| `：` | `:` |
| `；` | `;` |
| `，` | `,` |
| `＝` | `=` |
| `⇒` | 无 |
| `▷` | 无（管道） |

## 5. 语法

### 5.1 一个文件的组成

```
文件 = 语句*

语句 = 变量绑定
     | 赋值
     | 函数定义
     | 条件
     | 遍历
     | 循环
     | 返回
     | 尝试
     | 抛出
     | 引用模块
     | 表达式语句
```

### 5.2 块

块用 `【 】` 包围，不用缩进：

```
判 【
  分 > 60 ⇒ 【
    显("及格")
    显("恭喜")
  】
  它 ⇒ 显("不及格")
】
```

块内可以用换行或 `；` 分隔语句。

## 6. 数据类型

| 类型 | 例子 | 说明 |
|---|---|---|
| 数 | `42`、`3.14` | 整数与小数统一为「数」 |
| 字 | `"你好"` | 字符串，UTF-8 |
| 真/假 | `真`、`假` | 布尔 |
| 空 | `空` | 类似 None / null |
| 列 | `[1, 2, 3]` | 列表，可混合类型 |
| 表 | `{ "名" ⇒ "甲" }` | 字典，键是字 |
| 法 | `匠 加(甲, 乙) 【 … 】` | 函数（一等值） |

### 类型检查

```
型(值)         注 返回 "数" / "字" / "真" / "空" / "列" / "表" / "法"
```

真值判定：`假`、`空`、`0`、`""`、`[]`、`{}` 为假，其余为真。

## 7. 变量与作用域

### 7.1 绑定（定义）

```
42 名 答案          注 值在左
"张三" 名 姓名
[1, 2, 3] 名 列
```

### 7.2 赋值（修改）

```
43 易 答案          注 易 = 改变
```

`名` 是定义（不能重复定义同名），`易` 是修改（必须先定义过）。

### 7.3 作用域

- 函数内部定义的变量**局部**，函数外看不到
- 块（`【 】`）**不产生新作用域** —— 这和 Python 不同
- 内部可以读到外部变量；要修改外部变量用 `易`

```
0 名 计数
匠 加一() 【
  计数 + 1 易 计数       注 直接改外层的 计数
】
```

## 8. 运算符

### 8.1 算术

```
+ - * / %
```

`+` 对两个「字」是拼接，对「列」是合并：

```
显("甲" + "乙")             注 甲乙
显([1, 2] + [3])            注 [1, 2, 3]
```

`/` 结果总是小数；要取整用 `整()`。

### 8.2 比较

```
== != < <= > >=
```

### 8.3 逻辑

```
且   或   非
```

短路求值：`且` 左边假就不算右边，`或` 左边真就不算右边。

### 8.4 管道

```
▷
```

把左边作为右边函数的**第一个参数**：

```
[3, 1, 2] ▷ 排 ▷ 显          注 等价于 显(排([3, 1, 2]))
"abc" ▷ 长 ▷ 显               注 等价于 显(长("abc"))
```

### 8.5 优先级（低 → 高）

| 级 | 运算 |
|---|---|
| 1 | `或` |
| 2 | `且` |
| 3 | `非` |
| 4 | `== != < <= > >=` |
| 5 | `▷` |
| 6 | `+ -` |
| 7 | `* / %` |
| 8 | 一元 `-` |
| 9 | 调用 `f()`、取下标 `a[0]`、取成员 `a.b` |

## 9. 控制流

### 9.1 条件

两种形式。

**形式一：按值匹配（像 switch）**

```
判 等级 【
  1 ⇒ 显("一级")
  2 ⇒ 显("二级")
  它 ⇒ 显("其它")
】
```

**形式二：按真假**

```
判 【
  分 >= 90 ⇒ 显("优")
  分 >= 60 ⇒ 显("及格")
  它 ⇒ 显("不及格")
】
```

> 区分方法：`判` 后面**直接跟一个值**的是形式一；跟 `【` 的是形式二。

### 9.2 遍历

```
遍 项 于 [10, 20, 30] 【
  显(项)
】
```

遍历表时拿到的是**键**：

```
遍 键 于 { "甲" ⇒ 1, "乙" ⇒ 2 } 【
  显(键 + "=" + 串(表[键]))
】
```

### 9.3 区间循环

```
环 序 自 0 至 5 步 1 【
  显(序)                注 0 1 2 3 4（不含 5）
】
```

语法：`环 <变量名> 自 <起> 至 <终> 步 <步长> 【 … 】`
终值**不包含**在内；步长可为负数（倒着走）。

`步` 可以是负数（倒着走）。

### 9.4 跳出与继续

```
断                     注 break
续                     注 continue
```

### 9.5 函数提前返回

```
匠 找(项们, 目标) 【
  遍 项 于 项们 【
    判 项 == 目标 【
      真 ⇒ 归 真
      它 ⇒ 空
    】
  】
  归 假
】
```

## 10. 函数

### 10.1 定义与调用

```
匠 加(甲, 乙) 【
  归 甲 + 乙
】

显(加(1, 2))                 注 3
加(3, 4) ▷ 显                注 7
```

`匠` = 函数（工匠）。`归` = 返回。

### 10.2 匿名函数

```
排(列, 节 (项) 【 归 0 - 项 】) 名 倒序
```

`节` 是匿名函数（像 lambda）。

### 10.3 高阶函数

函数是一等值，能传能返：

```
匠 应用(法, 值) 【
  归 法(值)
】

显(应用(节 (项) 【 归 项 * 2 】, 5))      注 10
```

### 10.4 默认参数

无。需要可选参数时传 `空` 并判断：

```
匠 打招呼(对方, 前缀) 【
  判 【
    前缀 == 空 ⇒ 归 "你好，" + 对方
    它 ⇒ 归 前缀 + 对方
  】
】
```

### 10.5 递归

```
匠 阶乘(甲) 【
  判 甲 <= 1 【
    真 ⇒ 归 1
    它 ⇒ 归 甲 * 阶乘(甲 - 1)
  】
】
```

## 11. 错误处理

### 11.1 抛出

```
抛 "出错了"
抛 值误("年龄不能为负")
```

### 11.2 捕获

```
试 【
  1 / 0 名 危险
】 捕 误 【
  显("出错了：" + 误["说明"])
】
```

`误` 是一个表，含 `类`、`说明`、`行`、`列`。

### 11.3 收尾

```
试 【
  做点事()
】 捕 误 【
  显(误["说明"])
】 终 【
  清理()                 注 无论成功失败都执行
】
```

### 11.4 错误类型（14 种）

| 类 | 场景 |
|---|---|
| `法误` | 语法错误 |
| `名误` | 名字未定义 |
| `型误` | 类型不匹配 |
| `值误` | 值非法（如除零） |
| `参误` | 参数个数不对 |
| `索误` | 下标越界 |
| `键误` | 表里没有这个键 |
| `属误` | 对象没有这个成员 |
| `零误` | 除以零 |
| `时误` | 超时 |
| `内误` | 内部错误 |
| `断误` | `断` 用在了循环外 |
| `义误` | 自定义错误 |
| `法误` | 运行错误 |

错误的文本格式统一是 `第 N 行 第 M 列：<类>：<说明>`。

## 13. Web 开发

爻语内置 HTTP 服务器。**不依赖 Flask/Django**。

```
共("public", "/static")            注 把 public/ 目录挂到 /static 下

路("GET", "/", 节 (请) 【
  归 应(200, { "Content-Type" ⇒ "text/html; charset=utf-8" }, "你好")
】)

路("GET", "/api/问候/:名", 节 (请) 【
  归 { "问候" ⇒ "你好，" + 请.参["名"] }
】)

路("POST", "/api/加", 节 (请) 【
  归 { "果" ⇒ 请.体["甲"] + 请.体["乙"] }
】)

听 8788                            注 开始监听，阻塞
```

### 请求对象 `请`

| 字段 | 说明 |
|---|---|
| `请.法` | 方法（GET/POST/…） |
| `请.径` | 路径 |
| `请.参` | 表：路径参数 + 查询参数 |
| `请.体` | 表：请求体（JSON 自动解析） |
| `请.头` | 表：请求头（键小写） |
| `请.问` | 查询字符串表 |

### 响应函数 `应`

```
应(状态码, 头表, 体)
```

体可以是字、表（自动 JSON）、字节。

### 服务器内置函数

| 名 | 作用 |
|---|---|
| `路(法, 径, 法)` | 注册路由 |
| `共(目录, 挂载路径?)` | 静态文件 |
| `听(端口)` | 开始监听 |
| `停()` | 停止 |

## 已知限制

- 没有类/对象系统（用表和函数代替）
- 没有模块级命名空间（`引` 是文本级加载）
- 没有生成器/异步
- 没有默认参数、没有关键字参数
- 循环、条件都靠中文符号，非中文键盘输入不便
- 解释执行，性能约为 CPython 的 1/5
