# 用爻语写网页系统

爻语内置一套轻量网页运行时（`yao/web.py`，基于标准库 `http.server`），
**后端逻辑完全用爻语编写**，无需 Python。

一个最小可运行的网站：

```yao
路("GET", "/", 节 (请) 【
  归 "<h1>你好，爻语</h1>"
】)

听 8788
```

```powershell
爻语\解释器\exe\yao.exe 跑 网站.yao
# 打开 http://127.0.0.1:8788/
```

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻语\解释器\exe\yao.exe 程序.yao      # 推荐：单文件，无依赖
> 爻语\解释器\exe\yao.exe 程序.yao        # 备选：开发时用，功能更全
> ```
>
> **能力差异**：`yao.exe`（C 版）支持语言核心语法、75 个内置函数里的 48 个，
> 但**不含** Web 服务、MQTT、Modbus TCP。做网页后端或工业物联请用 Python 版。
> 完整对照见 [手册.md](手册.md#解释器版本对照)。

## 1. 四个内置 · 一个对象

| 内置 | 用途 |
|---|---|
| `路(法, 径, 处理函数)` | 注册路由 |
| `共(目录, 前缀?)` | 挂载静态文件目录 |
| `应(码, 头?, 体?)` | 构造响应（状态码 / 头 / 体） |
| `听(端口?)` | 启动服务（阻塞，直到 Ctrl+C） |
| `请` | 当前请求对象（每次请求自动更新） |

处理函数可以用两种写法，**都支持**：

```yao
注 写法一：1 个参数，形参就是请求对象（推荐）
路("GET", "/a", 节 (请) 【 归 请.径 】)

注 写法二：0 个参数，读全局「请」
路("GET", "/b", 节 () 【 归 请.径 】)
```

也可以用不写括号的命令式调用（语句级语法糖）：

```yao
路 "GET" "/c" 节 (请) 【 归 请.法 】
```

## 2. 路由

### 2.1 精确路径

```yao
路("GET", "/api/时间", 节 (请) 【 归 { "现在" ⇒ 今() } 】)
```

### 2.2 路径参数 `:名`

```yao
路("GET", "/事项/:编号", 节 (请) 【
  归 { "你请求的编号" ⇒ 请.参["编号"] }
】)
```

`:编号` 匹配任意非空单段，值写入 `请.参`。**路径参数名可以用中文。**

### 2.3 查询参数

`/搜索?词=爻语&页=2` 会合并进 `请.参`：

```yao
路("GET", "/搜索", 节 (请) 【
  归 {
    "词" ⇒ 取(请.参, "词", ""),
    "页" ⇒ 取(请.参, "页", "1")
  }
】)
```

### 2.4 各方法

`路` 的第一个参数是方法字符串，任意大写 HTTP 方法都可以：`GET`、`POST`、`PUT`、`PATCH`、`DELETE`、`HEAD`。

```yao
路("DELETE", "/事项/:编号", 节 (请) 【 … 】)
```

同一方法 + 同一路径**后注册的覆盖先注册的**。

## 3. 请求对象 `请`

| 字段 | 类型 | 说明 |
|---|---|---|
| `请.法` | 字 | `GET` / `POST` / … |
| `请.径` | 字 | URL 路径（已解码），如 `/事项/3` |
| `请.参` | 表 | 路径参数 + 查询参数合并 |
| `请.体` | 值 | 按 Content-Type 自动解析（见下） |
| `请.头` | 表 | 请求头，**键为小写** |
| `请.原` | 字 | 原始请求体字符串 |

`请.体` 的解析规则：

| Content-Type | `请.体` 的值 |
|---|---|
| `application/json` | 自动解析成表/列/数/字（`null` → `空`） |
| `application/x-www-form-urlencoded` | 表 |
| 其它 / 空 | 原始字（无体时为空字 `""`？不，为 `空`） |

```yao
路("POST", "/api/事项", 节 (请) 【
  取(请.体, "内容", "") 名 内容
  归 { "收到" ⇒ 内容 }
】)
```

> 请求路径里的中文需要百分号编码（HTTP 规范），浏览器 `fetch` 与 `XMLHttpRequest` 会自动处理；
> 用 `curl` 测试时请用 `%E4%BA%8B%E9%A1%B9` 这样的形式。

## 4. 返回值 → 响应

处理函数**返回什么，服务端就自动给什么响应**：

| 返回 | 状态码 | Content-Type | 体 |
|---|---|---|---|
| 字 | 200 | `text/html; charset=utf-8` | 原样 |
| 表 / 列 / 数 / 真 / 假 | 200 | `application/json; charset=utf-8` | JSON（中文不转义） |
| `空` | 204 | — | 空 |
| `应(码, 头, 体)` | 指定 | 指定 | 指定 |
| 抛错 | 500 | `application/json` | `{"错": "第 N 行 第 M 列：…"}` |

### 4.1 返回 JSON

```yao
路("GET", "/api/健康", 节 (请) 【
  归 { "行" ⇒ 真, "版本" ⇒ 版本(), "时间" ⇒ 今() }
】)
```

浏览器访问得到：

```json
{"行": true, "版本": "0.1.0", "时间": "2026-10-20 01:23:45"}
```

### 4.2 自定义状态码与头

```yao
路("POST", "/api/事项", 节 (请) 【
  归 应(
    201,
    { "Content-Type" ⇒ "application/json; charset=utf-8", "X-总数" ⇒ "1" },
    { "编号" ⇒ 1 }
  )
】)
```

> **响应头必须是 ASCII**（HTTP 规范）。头名或头值含中文会得到 `500` + 中文说明：
> `网误：响应头「X-说明」的值含非 ASCII 字符（…中文内容请放进响应体）`。

### 4.3 返回 HTML

```yao
路("GET", "/", 节 (请) 【
  归 "<!DOCTYPE html><html><body><h1>爻语待办</h1></body></html>"
】)
```

页面较大时写在单独文件里再读进来（`读` 相对**进程工作目录**）：

```yao
路("GET", "/", 节 (请) 【
  归 读("爻语/示例/待办/页面.html")
】)
```

## 5. 静态文件

```yao
共 "爻语/示例/待办/公共"           注 挂到 /公共/ 下
共 "静态资源", "/资"              注 挂到 /资/ 下
```

请求 `/公共/样式.css` 就会返回 `爻语/示例/待办/公共/样式.css`。

安全限制：路径解析后必须落在该目录内，`..` 越界一律 404。

## 6. 启动与端口

```yao
听 8788          注 显式端口
听               注 读环境变量「爻_端口」，再默认 8788
```

`听` 是**阻塞**调用，之后的语句不会执行。启动后控制台会打印：

```
爻语 0.1.0 网页服务已启动：http://127.0.0.1:8788/
```

`Ctrl+C` 结束。程序退出码 0。

> `听` 在在线 IDE 的沙箱中被禁用（在线环境不能开监听）。

## 7. 状态与并发

- 整个解释器在所有请求间**共享**，用全局锁串行化，所以用普通变量（`名`/`易`）存状态是安全的。
- 状态在**内存**里：进程重启即清空，持久化请用 `写()` / `读()` 或数据库外挂。
- 每个请求都会替换全局 `请`，处理函数返回后恢复。

```yao
[] 名 事项
0 名 序号

路("GET", "/api/事项", 节 (请) 【 归 事项 】)

路("POST", "/api/事项", 节 (请) 【
  序号 + 1 易 序号
  { "编号" ⇒ 序号, "内容" ⇒ 取(请.体, "内容", "") } 名 项
  增(事项, 项)
  归 应(201, { "Content-Type" ⇒ "application/json; charset=utf-8" }, 项)
】)
```

## 8. 完整示例：待办网站

仓库里 [`爻语/示例/待办/`](../爻语/示例/待办/) 是一个**纯爻语**写成的待办网站：

| 文件 | 作用 |
|---|---|
| `主.yao` | 全部后端逻辑：路由、增删改查、静态目录、启动 |
| `页面.html` | 前端页面（原生 JS `fetch` 调用接口） |
| `公共/样式.css` | 样式 |

运行：

```powershell
爻语\解释器\exe\yao.exe 跑 examples\待办\主.yao
```

打开 <http://127.0.0.1:8788/>，可以添加、勾选完成、删除、刷新保持。

### 后端关键代码

```yao
[] 名 事项
0 名 序号

匠 新增(体) 【
  序号 + 1 易 序号
  { "编号" ⇒ 序号, "内容" ⇒ 取(体, "内容", ""), "完成" ⇒ 假 } 名 项
  增(事项, 项)
  归 应(201, { "Content-Type" ⇒ "application/json; charset=utf-8" }, 项)
】

匠 找项(号) 【
  空 名 果
  遍 项 于 事项 【
    判 项["编号"] == 号 【
      真 ⇒ 项 易 果
      它 ⇒ 空
    】
  】
  归 果
】

匠 切换(号) 【
  找项(号) 名 项
  判 项 【
    空 ⇒ 归 应(404, { "Content-Type" ⇒ "application/json; charset=utf-8" }, { "错" ⇒ "没有这一项" })
    它 ⇒ 【
      非 项["完成"] 易 项["完成"]
      归 项
    】
  】
】

路("GET", "/", 节 (请) 【 归 读("爻语/示例/待办/页面.html") 】)
路("GET", "/api/事项", 节 (请) 【 归 事项 】)
路("POST", "/api/事项", 节 (请) 【 归 新增(请.体) 】)
路("PATCH", "/api/事项/:号", 节 (请) 【 归 切换(数(请.参["号"])) 】)

共 "爻语/示例/待办/公共"
听 8788
```

`页面.html` 里就是这样调用的：

```javascript
await fetch('/api/事项', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ 内容: '写爻语' })
});
```

## 9. 调试技巧

| 需求 | 做法 |
|---|---|
| 看请求内容 | 处理函数里 `显(请.法, 请.径, 请.参)`，输出到启动服务的控制台 |
| 出错不要 500 | 用 `试/捕` 包住，返回自己的错误结构 |
| 端口被占用 | 换端口，或先杀占用进程 |
| 跨域（前端在别的端口） | 处理函数里返回 `应(200, { "Access-Control-Allow-Origin" ⇒ "*" }, 数据)` |
| 想返回非 HTML 纯文本 | `应(200, { "Content-Type" ⇒ "text/plain; charset=utf-8" }, "文本")` |

## 10. 与「在线 IDE」的区别

| | 网页运行时（本文档） | 在线 IDE |
|---|---|---|
| 命令 | `爻语\解释器\exe\yao.exe 网站.yao` | `爻语\解释器\exe\yao.exe 站` |
| 端口 | 你自己 `听` 的端口（如 8788） | 默认 8787 |
| 用途 | 跑你自己写的网站 | 在浏览器里写/跑代码片段 |
| 沙箱 | 无限制 | 子进程 + 5 秒超时 + 禁 `读/写/在/引/听/路/共/停` |

两者互不干扰，可以同时开。
