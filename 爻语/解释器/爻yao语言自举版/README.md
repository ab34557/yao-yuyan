# 自举解释器（爻语写的爻语解释器）

> **这是一个用爻语自己写的爻语解释器。**
> 语言能实现自身 —— 这是自举（self-hosting）的判定标准。

---

## 这是什么

```
爻语程序源码  →  [爻语写的解释器]  →  执行结果
                      ↑
                 这个解释器本身
                 也是爻语写的（1883 行）
```

Python 版解释器（`../python版/`）同样能跑爻语程序，但那是 Python 实现的。
**这个版本完全用爻语写成** —— 词法、语法、求值、执行四层全部是爻语代码。

## 怎么用

### 一条命令（推荐，全程不需要 Python）

```powershell
爻语\解释器\exe\yao.exe 自举 你的程序.yao
```

就这一条。`yao.exe`（120 KB C 程序）会：

1. 找到自举解释器 `解释器.yao`
2. 读入你的程序源码
3. 用**爻语写的解释器**执行它

输出示例：

```
爻语\解释器\exe\yao.exe 自举 爻语\示例\示例\你好.yao

你好，世界！我是一门中文编程语言，名叫爻语。
一加一等于2
七除以二等于3.5
...
```

### 自举解释器在哪

`yao.exe` 按这个顺序找：

1. 环境变量 `YAO_SELFHOST` 指定的路径
2. 程序所在目录下的 `解释器.yao` / `../解释器/自举版/解释器.yao`
3. 当前目录下的 `解释器.yao`
4. `爻语/解释器/自举版/解释器.yao`
5. `爻语\解释器\自举版\解释器.yao`

**在项目根目录直接跑就行**，无需配置。

### 三种调用方式对比

| 方式 | 命令 | 需要 Python |
|---|---|---|
| **exe 自举**（推荐） | `yao.exe 自举 程序.yao` | ❌ 不需要 |
| exe 普通 | `yao.exe 程序.yao` | ❌ 不需要 |
| Python 开发 | `python -m yao 自举 程序.yao` | ✅ 需要 |

前两种都是 exe，区别是：
- **普通模式**：用 C 版解释器直接执行 → 快
- **自举模式**：用爻语写的解释器执行 → 慢，但验证自举

## 核心 API

`解释器.yao` 对外只暴露一个入口：

```yao
匠 自举解释(源码) 【
  切分(源码) 名 记号们          注 词法：字符串 → 记号
  解析程序(记号们) 名 程序      注 语法：记号 → AST
  造全局环境() 名 全局          注 建作用域
  执行语句们(程序, 全局) 名 果   注 执行
  判 【
    果["型"] == "抛" ⇒ 【
      显("【自举解释器】运行时错误：", 串(取(果["值"], "说明", 果["值"])))
      归 假
    】
    它 ⇒ 归 真
  】
】
```

内部四层：

| 层 | 关键函数 |
|---|---|
| 词法 | `新词法器` `切分` `扫标识` `扫数字` `扫字串` `扫注释` |
| 语法 | `新语法器` `解析程序` `解析语句` `解析表达式` `解析匠` `解析判` |
| 求值 | `求值` `求值名` `求二元` `求调用` `调匠` `加` `减` `乘` `除` |
| 执行 | `执行语句们` `执行语句` `执行判` `执行循` `执行遍` |
| 环境 | `新环境` `环境定义` `环境查找` `环境赋值` `造全局环境` |

## 已知限制

| 限制 | 说明 |
|---|---|
| **需要大栈** | Python 宿主下必须 `stack_size(64MB)`；C 版已内置 256MB 栈 |
| **慢** | 比 Python 版慢约 50-100 倍（解释器套解释器） |
| **无 Web/物联网** | 只实现语言核心，没有 `路`/`听`/`联`/`读寄` |
| **无文件 IO** | 没有 `读`/`写`（启动器用外层解释器读文件） |
| **输出格式微差** | 列打印少个空格：`[1,2,3]` 而非 `[1, 2, 3]` |
| **不支持下标赋值** | `t["a"] 易 ...` 在自举解释器里报「不能用下标访问」 |

> 最后一条是**自举代码本身的限制**，不是宿主解释器的问题 ——
> 用 Python 版跑同样的自举解释器也会报同样的错。

> 它是**教学级/验证级**实现，用来证明语言可自举，不是日常使用的解释器。
> 日常请用 `../python版/`。

## 三个宿主都能跑它

这是本轮验证的关键结论：**自举解释器不绑定 Python**。

| 宿主 | 状态 | 说明 |
|---|---|---|
| **Python 版解释器** | ✅ | 需要 64MB 栈 + 递归上限 30000 |
| **C 版 yao.exe（114 KB）** | ✅ | 已内置 256MB 栈，开箱即用，无需 Python |
| **另一个自举解释器** | 理论可行 | 会非常慢，未做完整验证 |

# C 版跑自举解释器 —— 不需要任何 Python

## 为什么值得做

自举是编程语言成熟度的标志：

- **证明语法完备** —— 语言的表达能力足以描述自己
- **证明语义自洽** —— 没有「只有宿主语言才做得到」的隐藏特性
- **发现设计缺陷** —— 写不下去的地方就是语言设计的问题

这个项目在写自举版时确实发现了问题，比如：
`断`（break）在循环外使用没有编译期检查、`易` 的作用域查找规则不够明确等。
