# 爻语（Yao）

用**中文单字作关键字**的编程语言。值在左、名字在右（`42 名 答案`），
块用 `【 】`，可用中文写网页后端、工业物联网、命令行工具。

#### 用 yao.exe 运行自举解释器 ✅

这是本轮打通的能力 —— **C 版 exe 能运行爻语写的解释器**：

```powershell
# 准备：把自举解释器和目标程序拼在一起
# 实际用法见 解释器/自举版/README.md
爻语\解释器\exe\yao.exe <自举解释器+程序>.yao
```

自举解释器由 1883 行爻语写成，`yao.exe` 完整执行它，
再由它解释目标爻语程序 —— 三层都跑通。

### 自举版/ —— 用爻语写的解释器

**这门语言能实现自己的解释器**，这是自举（self-hosting）的判定标准。

```powershell
# 一条命令：用爻语写的解释器跑你的程序（全程不需要 Python）
爻语\解释器\exe\yao.exe 自举 示例\示例\你好.yao
```

就这一条。`yao.exe` 会找 `解释器.yao`、读入你的程序、用**爻语写的解释器**执行。

文件：`解释器.yao`（1883 行，92 个顶层函数，四层完整实现）+ `自举运行.yao`（启动器）。

实测 **12/12 通过**：算术、变量、函数、递归、条件、循环、遍历、字符串、列、表、闭包、异常。

> 详细说明见 [解释器/自举版/README.md](解释器/自举版/README.md)。
> 它是**验证级实现**，比 Python 版慢 50-100 倍，日常请用 python版。

### C版/ —— 源码

`lexer.c` `parser.c` `eval.c` `builtins.c` `main.c`（共 3673 行）。
用 `C版/构建工具/tcc`（内置 TinyCC）编译，不需要装 Visual Studio。

> **说明**：C 版是学习/嵌入式用途的轻量实现，功能少于 Python 版。
> 项目的主力是 Python 版和自举版。
