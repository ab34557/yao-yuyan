爻语（Yao）解释器 —— 独立可执行版
================================================================

## 这是什么

爻语是一门中文编程语言。这个 yao.exe 是它的解释器，
**单文件，不需要安装任何东西**（不需要 Python、不需要运行库）。


## 怎么用

### 方式一：把 .yao 文件拖到 yao.exe 上
最简单。程序跑完后窗口会停住，按回车才关闭，方便看结果。

### 方式二：双击 .yao 文件
和拖拽一样。前提是这个文件已经关联到 yao.exe。
跑完后同样会暂停等回车。

### 方式三：命令行
在文件管理器地址栏输入 cmd 回车，然后：

    yao.exe 你的程序.yao

命令行方式**不会**暂停 —— 因为结果直接在终端里，不需要留住窗口。

### 方式四：双击 yao.exe（不带文件）
进入交互式 REPL，可以一行一行输入代码：

    爻> 显("你好")
    你好
    爻> 1 + 2
    3
    爻> help
    （显示帮助）
    爻> 出 0
    （退出）

> 提示：双击 / 拖拽方式的「按回车关闭」可以用环境变量关掉：
>     set YAO_NO_PAUSE=1
> 适合做快捷方式、批处理、自动化脚本时使用。


## 常用命令

    yao.exe 程序.yao          运行程序
    yao.exe --check 程序.yao  只检查语法，不运行
    yao.exe --version         显示版本
    yao.exe --help            显示帮助
    yao.exe                   进入 REPL


## 第一个程序

用记事本（保存时选 UTF-8 编码）写：

    显("你好，世界")
    42 名 答案
    显("答案是 ", 答案)

保存为 `测试.yao`，然后：

    yao.exe 测试.yao


## 语言速览

赋 值：值在前，名字在后
    42 名 答案          ← 把 42 叫作「答案」
    答案 + 1 易 答案    ← 把答案改成 43

函 数：
    匠 加(甲, 乙) 【
      归 甲 + 乙
    】
    显(加(3, 4))        ← 7

条 件：
    判 分数 >= 60 【
      真 ⇒ 显("及格")
      它 ⇒ 显("不及格")
    】

循 环：
    0 名 i
    循 i < 5 【
      显(i)
      i + 1 易 i
    】

或者：
    环 i 自 0 至 5 【 显(i) 】

集合：
    [1, 2, 3] 名 列
    { "甲" ⇒ 1, "乙" ⇒ 2 } 名 表
    显(长(列))                    ← 3
    显(取(表, "甲", 0))           ← 1

高阶函数：
    映([1,2,3], 节 (x) 【 归 x * x 】)       ← [1, 4, 9]
    筛([1,2,3,4], 节 (x) 【 归 x % 2 == 0 】) ← [2, 4]

错误处理：
    试 【
      1 / 0 名 危险
    】 捕 误 【
      显("捕获到错误")
    】


## 能做什么

✅ 全部语言语法（条件/循环/函数/闭包/递归/异常）
✅ 75 个内置函数
✅ 文件读写（中文路径支持）
✅ JSON 解析与生成
✅ Web 服务（写后端接口）
✅ MQTT / Modbus（工业物联网）
✅ HTTP 客户端 / TCP
✅ 多线程

写个 Web 服务：

    路("GET", "/api/问候", 节 (请) 【
      归 { "消息" ⇒ "你好" }
    】)
    听(8800)

然后浏览器打开 http://127.0.0.1:8800/api/问候


## 注意

- .yao 文件必须保存为 **UTF-8 编码**（记事本默认可能不是）
- 中文路径和中文文件名都支持
- 程序出错会显示 `第 N 行 第 M 列：错误说明`
