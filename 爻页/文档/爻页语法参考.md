# 爻页语法完整参考

> 爻页（YaoPage）是**界面描述语言**，用来写 GUI 程序。
> 它不生成 HTML/CSS/JS —— 渲染器用 Python 标准库 tkinter 从零实现。
>
> 姊妹语言：[爻语语法参考.md](爻语语法参考.md)（后端/通用编程语言）。
> 本文是语法参考，入门请看 [爻页/文档/手册.md](../爻页/文档/手册.md)。

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻页\浏览器\爻页浏览器.exe 页面.页       # 推荐：单文件，可直接分发
> 爻页\浏览器\爻页浏览器.exe 页面.页            # 备选：开发时用
> ```
>
> `爻页浏览器.exe`（14.9 MB）内嵌 Python 运行时，**不需要目标机器装 Python**，
> 但引擎本身是 Python 实现（tkinter 渲染）。它就是这个语言的解释器 + 浏览器。

## 一、爻页是什么

传统 Web 前端要写 HTML（结构）+ CSS（样式）+ JS（逻辑）三种语言。
爻页用**一种语言**描述全部：

| 用 HTML/CSS/JS | 用爻页 |
|---|---|
| `<div style="padding:20px"><p>你好</p></div>` | `竖 填 20 【 文 "你好" 】` |
| `<style>.box{background:#111}</style>` | `底 "#111"` |
| `let n = 0;` | `0 态 n` |
| `onclick="n++"` | `钮 "加" 点 【 置 n n + 1 】` |

**共有 58 个保留字**：4 个结构 + 8 个元素 + 19 个修饰 + 16 个语句 + 6 个逻辑 + 对齐值等。

## 二、词法

### 2.1 注释

```yao-fragment
注 这是注释
```

### 2.2 字面量

| 类型 | 写法 |
|---|---|
| 数 | `42`、`3.14` |
| 字 | `"你好"` |
| 列 | `[1, 2, 3]` |
| 表 | `{ "甲" ⇒ 1 }` |
| 真/假/空 | `真`、`假`、`空值` |

### 2.3 标识符

汉字、字母、下划线、数字（不能开头）。**不能是保留字，也不能以保留字结尾**
（因为词法按最长匹配，`终点` 会被切成 `终` + `点`）。

## 三、页面结构

一个页面就是一个 `.页` 文件，**根必须是一个 `页` 元素**：

```yao-fragment
页 "窗口标题" 【
  0 态 计数

  始 【
    "就绪" 易 提示
  】

  竖 填 20 缝 12 【
    文 "内容" 大 16
  】
】
```

完整骨架：

```yao-fragment
页 "我的应用" 【
  0 态 计数
  "" 态 提示

  始 【
    "就绪" 易 提示
  】

  竖 填 20 缝 12 底 "#0a0f1a" 【
    文 "计数 = " + 串(计数) 大 16 色 "#e2e8f0"
    钮 "加一" 点 【 置 计数 计数 + 1 】 底 "#7ee787" 色 "#06210f" 圆 6
    文 提示 大 12 色 "#94a3b8"
  】
】
```

## 四、元素（8 个）

### 4.1 容器（3 种）

| 元素 | 说明 |
|---|---|
| `竖 修饰… 【 子元素… 】` | 纵向排列（子元素从上到下） |
| `横 修饰… 【 子元素… 】` | 横向排列（子元素从左到右） |
| `层 修饰… 【 子元素… 】` | 叠放（子元素互相覆盖，后写的在上） |

```yao-fragment
竖 填 16 缝 10 底 "#111" 【
  文 "第一行"
  文 "第二行"
】

横 缝 8 【
  钮 "左"
  钮 "右"
】

层 【
  图 "背景.png"
  文 "覆盖在图片上的字" 色 "#fff"
】
```

### 4.2 内容元素（4 种）

| 元素 | 说明 | 示例 |
|---|---|---|
| `文 内容 修饰…` | 文本 | `文 "你好" 大 16 粗` |
| `钮 文字 点 【 事件 】 修饰…` | 按钮 | `钮 "确定" 点 【 置 n 1 】` |
| `输 状态名 修饰…` | 输入框（直接绑定状态，自动双向同步） | `输 用户名` |
| `图 路径 修饰…` | 图片 | `图 "logo.png" 宽 64 高 64` |

### 4.2.1 输入框的绑定

`输` 后面**直接跟状态名**（不是初值），输入框和状态自动双向同步：

```
"" 态 账号

输 账号 宽 300 填 8 圆 6
```

用户打字 → 状态 `账号` 立即更新；程序里 `置 账号 "默认"` → 输入框内容跟着变。

> 注意：`输` 后面必须是**状态名**，不能是字面量（`输 ""` 会报错），
> 也不能写 `输 账号 归 账号`（多写了 `归` 会报「归不能作为元素」）。

### 4.3 装饰元素（2 种）

| 元素 | 说明 |
|---|---|
| `线 修饰…` | 分割线（水平细线） |
| `空 高度` | 占位空白（`空 2` = 8px 左右） |

### 4.4 列表渲染（1 种）

`列` 按数据源重复渲染子元素（相当于 `v-for`）：

```yao-fragment
[1, 2, 3] 态 数字们

列 项 于 数字们 【
  文 "第 " + 串(项) + " 项" 大 14
】 缝 6
```

**`列` 是元素级语句**，只能出现在元素位置（不能写在函数体里）。
循环变量 `项` 在子元素里可用。

列表也可以遍历表（`项` 是键）：

```yao-fragment
{ "甲" ⇒ 1 } 态 表
列 键 于 表 【
  文 键 + " = " + 串(取(表, 键, 空))
】
```

## 五、修饰（19 个）

修饰写在元素名后面、块前面，**空格分隔，顺序无关**：

```yao-fragment
钮 "确定" 底 "#7ee787" 色 "#06210f" 圆 6 大 12 填 8 点 【 … 】
```

### 5.1 盒子（4 个）

| 修饰 | 值 | 说明 |
|---|---|---|
| `填 数` | 数 | 内边距（padding），四边相同 |
| `缝 数` | 数 | 子元素间距（gap） |
| `宽 数` / `宽 满` | 数 \| 满 | 宽度。`满` = 撑满父容器 |
| `高 数` | 数 | 高度 |

### 5.2 文字（4 个）

| 修饰 | 值 | 说明 |
|---|---|---|
| `大 数` | 数 | 字号（px） |
| `色 "#rrggbb"` | 色 | 文字颜色 |
| `粗` | — | 加粗（无值） |
| `齐 左\|中\|右` | 对齐值 | 水平对齐 |

### 5.3 外观（8 个）

| 修饰 | 值 | 说明 |
|---|---|---|
| `底 "#rrggbb"` | 色 | 背景色 |
| `边 数` | 数 | 边框宽度 |
| `边色 "#rrggbb"` | 色 | 边框颜色 |
| `圆 数` | 数 | 圆角半径 |
| `悬底 "#rrggbb"` | 色 | 鼠标悬停时的背景色 |
| `线宽 数` | 数 | `图线` 的线宽 |
| `底线 "#rrggbb"` | 色 | `图线` 的底线颜色 |
| `点色 "#rrggbb"` | 色 | `图线` 的数据点颜色 |

### 5.4 行为（3 个）

| 修饰 | 值 | 说明 |
|---|---|---|
| `隐` | — | 隐藏元素（不占空间） |
| `手` | — | 鼠标移上去变手型（可点提示） |
| `横排` | — | 某些元素内横向排列 |

### 5.5 颜色写法

**只支持 `"#rrggbb"` 六位十六进制**，不支持 `#rgb`、颜色名、`rgba()`。

## 六、状态

### 6.1 声明—— `态`

**初始值在前，`态` 在中，名字在后**：

```yao-fragment
0 态 计数
"" 态 用户名
[] 态 列表
{} 态 表单
真 态 已登录
```

状态**自动双向绑定**：状态变了界面重绘，`置` 改状态触发更新。

### 6.2 修改—— `置`

```yao-fragment
置 计数 计数 + 1
置 用户名 "张三"
置 列表 [1, 2, 3]
```

**`置` 的第二个参数是表达式（新值）**，所以不需要引号包裹状态名。

### 6.3 读取

状态名直接在表达式里用：

```yao-fragment
文 "计数 = " + 串(计数)
置 总价 数量 * 单价
```

## 七、事件

### 7.1 点击—— `点`

只有 `钮` 支持点击：

```yao-fragment
钮 "提交" 点 【
  置 提交中 真
  行 提交表单()
  置 提交中 假
】 
```

**事件体里可以用**：`置` / `发` / `判` / `跳` / `调` / `行`，
以及「表达式 归/易 状态名」。

### 7.2 页面初始化—— `始`

页面加载完执行一次：

```yao-fragment
始 【
  行 加载数据()
  "加载中…" 易 提示
】
```

### 7.3 定时器—— `次 毫秒`

```yao-fragment
次 2000 毫秒 【
  行 刷新()
】
```

每 2000ms 执行一次，用于轮询后端。

### 7.4 页面跳转—— `跳`

```yao-fragment
钮 "去设置" 点 【 跳 "设置.页" 】
```

如果当前页面是从 URL 加载的，`跳 "总览.页"` 会跳转到 `/页/总览`。

### 7.5 调用后端—— `调` 与 `行`

| 写法 | 说明 |
|---|---|
| `行 函数()` | 执行函数，结果不关心 |
| `行 函数() 归 状态名` | 执行函数，结果写进状态 |
| `行 函数() 易 状态名` | 执行函数，结果修改已有状态 |

```yao-fragment
匠 刷新() 【
  抓("http://127.0.0.1:8795/api/快照") 归 响应
  析(取字段(响应, "文")) 归 数据
】

次 2000 毫秒 【
  行 刷新()
】
```

## 八、页面内函数—— `匠`

```yao-fragment
匠 加倍(值) 【
  回 值 * 2
】

匠 刷新() 【
  抓("http://127.0.0.1:8795/api/快照") 归 响应
  判 取(响应, "码", 0) == 200 【
    真 ⇒ 析(取字段(响应, "文", "{}")) 归 数据
  】
  回 1
】
```

### 8.1 函数体支持的语句

**只有这些**：
`置` / `发` / `判` / `跳` / `调` / `回`，以及「表达式 归/易 状态名」。

**两个重要限制**：

**1. 不支持 `循` 和 `列`** —— 爻页没有循环语句。
需要遍历数据时在**元素位置**用 `列`，或让后端返回算好的结果。

**2. 不能有纯表达式语句** —— 每个表达式都必须「落到一个状态上」：

```
匠 对() 【
  存("k", 1)           注 ✗ 法误：这里需要「归 状态名」或「易 状态名」
  1 + 2                注 ✗ 同样报错
】

匠 对() 【
  行 存("k", 1)         注 ✓ 用 行 前缀表示「只执行，不关心结果」
  1 + 2 归 结果         注 ✓ 落到状态
  回 1
】
```

> `行` 是「执行但不取值」的标记。凡是返回值用不上的函数调用，前面都要加 `行`。

### 8.2 返回值—— `回`

```yao-fragment
匠 求和(甲, 乙) 【
  回 甲 + 乙
】
```

`回` 不带值也可以（返回空）。

## 九、条件

### 9.1 语句位置：`判`

```yao-fragment
判 计数 > 10 【
  真 ⇒ 置 提示 "太大了"
  它 ⇒ 置 提示 "正常"
】
```

多臂：

```yao-fragment
判 【
  分数 >= 90 ⇒ 置 等级 "A"
  分数 >= 80 ⇒ 置 等级 "B"
  它 ⇒ 置 等级 "C"
】
```

### 9.2 元素位置：条件渲染

`判` 也可以写在元素位置，只渲染命中的分支：

```yao-fragment
判 已登录 【
  真 ⇒ 竖 【
    文 "欢迎回来"
    钮 "退出" 点 【 置 已登录 假 】
  】
  它 ⇒ 竖 【
    输 用户名 归 用户名
    钮 "登录" 点 【 行 登录() 】
  】
】
```

**注意元素位置的 `判` 分支臂必须是元素**（`真 ⇒ 竖 【 】`），
不能是语句（`真 ⇒ 置 x 1` 只在语句位置合法）。

## 十、表达式与运算符

### 10.1 运算符

与爻语相同：

| 类别 | 运算符 |
|---|---|
| 算术 | `+ - * / %` |
| 比较 | `== != < <= > >=` |
| 逻辑 | `且 或 非` |
| 分组 | `( )` |

**字符串拼接用 `+`**，数字转字用 `串()`：

```yao-fragment
文 "计数 = " + 串(计数) 大 14
```

### 10.2 内置函数（29 个）

**类型与转换**

| 名 | 签名 | 说明 |
|---|---|---|
| `串` | `串(值)` | 转字符串 |
| `数` | `数(值)` | 转数字 |
| `整` | `整(值)` | 取整 |
| `长` | `长(字\|列\|表)` | 长度 |

**字与列**

| 名 | 签名 | 说明 |
|---|---|---|
| `切` | `切(值, 起, 止?)` | 子串/子列 |
| `含` | `含(值, 子)` | 包含 |
| `连` | `连(列, 分隔?)` | 连接成字 |
| `拆` | `拆(字, 分隔?)` | 拆成列 |
| `截断` | `截断(字, 长?)` | 截断加省略号 |

**集合**

| 名 | 签名 | 说明 |
|---|---|---|
| `取` | `取(容器, 键, 默认?)` | 安全取值 |
| `置` | `置(表, 键, 值)` | 写表 |
| `增` | `增(列, 值)` | 追加 |
| `删` | `删(容器, 键)` | 删除 |
| `排` | `排(列)` | 排序 |
| `倒` | `倒(列)` | 反转 |
| `取字段` | `取字段(表, 键)` | **安全取字段**，取不到返回 `空值` |
| `有` | `有(表, 键)` | 键是否存在 |

**数学**

| 名 | 签名 | 说明 |
|---|---|---|
| `舍` | `舍(数, 位?)` | 四舍五入 |
| `绝` | `绝(数)` | 绝对值 |

**时间**

| 名 | 签名 | 说明 |
|---|---|---|
| `今` | `今()` | 当前时间 |

**JSON / HTTP**

| 名 | 签名 | 说明 |
|---|---|---|
| `析` | `析(文)` | 解析 JSON |
| `构` | `构(值)` | 生成 JSON |
| `抓` | `抓(网址)` | GET，返回 `{码, 文, 头}` |
| `请求` | `请求(网址, {法, 体, 头}?)` | 任意方法，**自动带登录令牌** |

**页面存储**（跨页面共享）

| 名 | 签名 | 说明 |
|---|---|---|
| `存` | `存(键, 值)` | 写入全局存储 |
| `载` | `载(键, 默认?)` | 读取 |
| `清` | `清(键?)` | 清除 |

> `连`/`拆` 不叫 `并`/`分`，因为 `并` 与逻辑关键字冲突。

### 10.3 请求后端

```yao-fragment
注 GET，不需要鉴权
抓("http://127.0.0.1:8795/api/设备") 归 响应
判 取(响应, "码", 0) == 200 【
  真 ⇒ 析(取字段(响应, "文", "[]")) 易 设备们
】

注 POST，自动带 X-Token
请求("http://127.0.0.1:8795/api/设备/CV-01/启停", {
  "法" ⇒ "POST",
  "体" ⇒ { "运行" ⇒ 真 }
}) 归 响应
```

`抓` / `请求` 返回的表：

| 字段 | 说明 |
|---|---|
| `码` | HTTP 状态码 |
| `文` | 响应体字符串 |
| `头` | 响应头 |

## 十一、布局

### 11.1 盒模型

```yao-fragment
┌──────── 外框（边 边色）────────┐
│  填（内边距）                  │
│   ┌──── 内容区 ────┐          │
│   │                │          │
│   └────────────────┘          │
└───────────────────────────────┘
```

### 11.2 尺寸规则

| 情况 | 行为 |
|---|---|
| 不写 `宽` | 由内容撑开 |
| `宽 320` | 固定 320px |
| `宽 满` | 撑满父容器宽度 |
| 不写 `高` | 由内容撑开 |
| `高 130` | 固定高度 |

### 11.3 `竖` / `横` 的排列

- `竖`：子元素从上到下，`缝` 是垂直间距
- `横`：子元素从左到右，`缝` 是水平间距
- `层`：所有子元素从同一位置开始叠放

### 11.4 文本折行

`文` 元素会按 `宽` 自动折行。不写 `宽` 就不折行（可能溢出）。

### 13.4 易错点

| 坑 | 说明 |
|---|---|
| **页面根必须唯一** | 一个 `.页` 文件只有一个顶格 `页 …【 】` |
| **`态` 值在前** | `0 态 计数` 不是 `态 计数 0` |
| **元素位置 `判` 只能给元素** | `真 ⇒ 置 x 1` 只在语句位置合法 |
| **`列` 只能写在元素位置** | 函数体里不能用 |
| **函数体不支持循环** | 只有 `置/发/判/跳/调/回/行` |
| **颜色只支持 `#rrggbb`** | 不支持 `#rgb`、颜色名、`rgba()` |
| **标识符不能以保留字结尾** | `终点` 会被切成 `终`+`点` |
| **`钮` 才有点击事件** | 容器 `横`/`竖` 不支持 `点` |
| **字符串拼接用 `+`** | 数字要 `串()` 转 |

## 十四、浏览器与工具

### 14.1 命令行

```powershell
爻页\浏览器\爻页浏览器.exe                     # 打开浏览器（欢迎页）
爻页\浏览器\爻页浏览器.exe 页面.页              # 打开指定页面
爻页\浏览器\爻页浏览器.exe --检 页面.页         # 只做语法检查
爻页\浏览器\爻页浏览器.exe --结构 页面.页       # 打印布局盒树（调试）
爻页\浏览器\爻页浏览器.exe --离屏 页面.页 出.png 900 700   # 渲染成图片
```yao-fragment

### 14.2 独立 exe

`bin\爻页浏览器.exe` —— 不依赖 Python 的单文件可执行程序，可直接分发。

```powershell
爻页浏览器.exe 页面.页
爻页浏览器.exe --检 页面.页
爻页浏览器.exe --离屏 页面.页 出.png
```

### 14.3 离线渲染（写测试用）

`--离屏` 不需要开窗口，可以直接在 CI 里验证界面渲染：

```powershell
爻页\浏览器\爻页浏览器.exe --离屏 爻语/示例/分拣监控/页面/登录.页 build/登录.png 900 700
```yao-fragment

### 14.4 已知限制

| 限制 | 说明 |
|---|---|
| 全量重绘 | 每次状态变化整个页面重绘，没有 diff（46 元素约 97ms） |
| 无动画 | 没有过渡/动画 API |
| 无滚动容器 | 内容超出窗口看不到 |
| 无表格元素 | 用 `竖`/`横` 拼 |
| 无图标库 | 用 `图` 加载图片 |
| 只有 Windows 的 exe | 其他平台需重新打包 |
