# 爻页浏览器使用说明

> 爻页浏览器是**渲染爻页（.页）程序的图形界面运行器**。
> 它不用 HTML/CSS/JS —— 内核是 Python 标准库 tkinter，从零实现的词法/语法/布局/渲染管线。
>
> 语言语法见 [爻页语法参考.md](爻页语法参考.md)。
> 想直接分发请看 [独立exe.md](独立exe.md)。

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻页\浏览器\爻页浏览器.exe 页面.页       # 推荐：单文件，可直接分发
> 爻页\浏览器\爻页浏览器.exe 页面.页            # 备选：开发时用
> ```
>
> `爻页浏览器.exe`（14.9 MB）内嵌 Python 运行时，**不需要目标机器装 Python**，
> 但引擎本身是 Python 实现（tkinter 渲染）。它就是这个语言的解释器 + 浏览器。

## 一、两种启动方式

### 1.1 开发模式（需要 Python）

```powershell
# 打开浏览器（显示欢迎页）
爻页\浏览器\爻页浏览器.exe

# 打开指定页面
爻页\浏览器\爻页浏览器.exe examples\分拣监控\页面\登录.页

# 打开远程页面（见第 5 节）
爻页\浏览器\爻页浏览器.exe http://127.0.0.1:8795/页/登录
```

### 1.2 独立 exe（不需要 Python）

```powershell
bin\爻页浏览器.exe                          # 双击也能开
bin\爻页浏览器.exe examples\分拣监控\页面\登录.页
bin\爻页浏览器.exe 登录.页                   # 只给文件名也能找
```

exe 是 14.9 MB 单文件，拷给别人双击即用。查找顺序：
**当前目录 → exe 目录 → 内置示例目录 → 资源目录**。

## 二、界面说明

启动后是一个 1000×760 的窗口（可拉伸，最小 560×420），从上到下分三层：

```text
┌──────────────────────────────────────────────────────────────┐
│  ←  →  ↻  │ 地址栏                    │ 打开 │ 选文件 │      │  ← 工具栏
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                                                              │
│                     渲染区（Canvas）                          │  ← 页面内容
│                                                              │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 就绪 · 元素 21 个 · 状态 7 个 · 渲染 9.9 ms                   │  ← 状态栏
└──────────────────────────────────────────────────────────────┘
```

### 2.1 工具栏

| 控件 | 作用 |
|---|---|
| `←` 后退 | 回到上一个页面（历史为空时禁用） |
| `→` 前进 | 前进到下一个页面 |
| `↻` 刷新 | 重新加载当前页面（等同于 F5） |
| 地址栏 | 显示当前页面路径，可编辑后按回车跳转 |
| `打开` | 跳转到地址栏里输入的地址 |
| `选文件` | 弹出文件对话框，选一个 `.页` 文件打开 |

### 2.2 窗口标题

- 未加载页面时：`爻页 浏览器 v0.1.0`
- 加载后：`<页面标题> — 爻页 浏览器`

页面标题来自 `.页` 文件里的 `页 "标题"`。

### 2.3 状态栏

每次渲染后更新，显示：

```text
<状态消息> · 元素 N 个 · 状态 M 个 · 渲染 T ms
```

| 部分 | 含义 |
|---|---|
| 状态消息 | 页面主动设置的消息 / 错误信息 / 加载来源 |
| 元素 N 个 | 本次布局产生的盒子总数 |
| 状态 M 个 | 页面声明的状态变量个数 |
| 渲染 T ms | 本次完整渲染耗时 |

**这个数字是判断性能的入口。** 46 个元素的页面约 97ms，是正常范围。

## 四、地址栏能输入什么

### 4.1 本地文件路径

```powershell
examples\分拣监控\页面\登录.页       # 相对路径
C:\我的页面\测试.页                  # 绝对路径
登录.页                             # 只给文件名（在搜索路径里找）
```

支持正斜杠 `/` 和反斜杠 `\`。

### 4.2 远程 URL

```powershell
http://127.0.0.1:8795/页/登录        # 从后端取爻页源码
https://example.com/page.页          # 任意 https
```

浏览器会 GET 这个 URL，把响应体当**爻页源码**解析渲染。

### 4.3 页面名（相对跳转）

页面里的 `跳 "总览.页"` 会智能解析：

| 当前页面来源 | `跳 "总览.页"` 解析为 |
|---|---|
| 本地文件 | 同目录下的 `总览.页` 文件路径 |
| 远程 URL | `<同主机>/页/总览` |

## 五、远程页面（前后端分离）

这是爻页浏览器最有用的能力：**爻页写的后端（爻语）提供页面，爻页浏览器渲染它**。

### 5.1 后端这边

用爻语写一个返回页面源码的路由：

```yao
"爻语/示例/分拣监控/页面" 名 页面根

路("GET", "/页/:名", 节 (请) 【
  请.参["名"] 名 页名
  判 【
    含(页名, "..") ⇒ 归 应(400, {}, { "错" ⇒ "非法页面名" })
  】
  页面根 + "/" + 页名 + ".页" 名 路径
  判 【 在(路径) == 假 ⇒ 归 应(404, {}, { "错" ⇒ "页面不存在" }) 】
  归 应(200, { "Content-Type" ⇒ "text/plain; charset=utf-8" }, 读(路径))
】)

路("GET", "/api/快照", 节 (请) 【
  归 { "在线" ⇒ 真, "总到达" ⇒ 123 }
】)

听(8795)
```

### 5.2 浏览器这边

```powershell
爻页浏览器.exe http://127.0.0.1:8795/页/登录
```

页面里的 `抓()` / `请求()` 会访问 `http://127.0.0.1:8795/api/...`，
所以**页面源码里的接口地址要写完整 URL**：

```yao-fragment
匠 刷新() 【
  抓("http://127.0.0.1:8795/api/快照") 归 响应
  析(取字段(响应, "文", "{}")) 归 数据
  回 1
】
```

### 5.3 登录令牌自动携带

`请求()` 会自动把全局存储里的 `令牌` 加到 `X-Token` 头：

```yao-fragment
注 登录成功后存令牌
请求("http://127.0.0.1:8795/api/登录", {
  "法" ⇒ "POST",
  "体" ⇒ { "账号" ⇒ 账号, "密码" ⇒ 密码 }
}) 归 响应

判 取(响应, "码", 0) == 200 【
  真 ⇒ 【
    析(取字段(响应, "文", "{}")) 归 登果
    行 存("令牌", 取字段(登果, "令牌"))
  】
】

注 之后所有 请求() 都自动带令牌
请求("http://127.0.0.1:8795/api/用户/列表", { "法" ⇒ "GET" }) 归 用户们
```

### 5.4 跨页面跳转

远程模式下的 `跳` 会**拼成 URL**，不需要改代码：

```text
钮 "去设备页" 点 【 跳 "设备.页" 】
```

在 `http://host:端口/页/登录` 里点它 → 跳到 `http://host:端口/页/设备`。

## 六、命令行参数（无界面用法）

除了开窗口，浏览器还能做无头（headless）工作：

### 6.1 语法检查（不开窗口）

```powershell
爻页\浏览器\爻页浏览器.exe --检 页面.页
爻页浏览器.exe --检 页面.页
```

输出：

```

```

出错时输出**带行列号的错误**，直接指出第几行第几列：

```
第 12 行 第 5 列：法误：这里需要「归 状态名」或「易 状态名」
```

### 6.2 打印布局盒树（调试布局）

```powershell
爻页\浏览器\爻页浏览器.exe --结构 页面.页
```

输出缩进的盒子树，每个盒子带坐标和尺寸：

```text
竖 (0,0) 1000×760  [填 16 缝 10]
  横 (16,16) 968×28
    文 (16,16) 340×28 "智能物料分拣监控与物联管理系统"
    钮 (366,16) 60×28 "总览"
    ...
```

**排查「元素位置不对」「宽度不生效」时用这个。**

### 6.3 渲染成图片（写测试用）

```powershell

```

参数：`--离屏 <页面> <输出图> [宽 高]`，默认 900×700。

不需要显示器，可在 CI 里跑。**这是验证界面外观最快的办法。**

### 6.4 帮助与版本

```powershell

```

## 七、页面里的请求能力

浏览器内置 4 个网络函数（详细签名见[爻页语法参考.md](爻页语法参考.md)）：

| 函数 | 用途 | 是否带令牌 |
|---|---|---|
| `抓(网址)` | GET 请求 | 否 |
| `请求(网址, 选项)` | 任意方法 | **是**（自动 `X-Token`） |

返回 `{ 码, 文, 头 }`：

```yao-fragment
抓("http://127.0.0.1:8795/api/设备") 归 响应
判 取(响应, "码", 0) == 200 【
  真 ⇒ 析(取字段(响应, "文", "[]")) 易 设备们
  它 ⇒ "请求失败：" + 串(取(响应, "文", "")) 易 提示
】
```

### 7.1 跨域问题

**爻页浏览器没有同源策略限制。** 页面在本地文件里跑，可以请求任意地址。
这是桌面应用和网页的关键区别 —— 不用配 CORS。

### 7.2 超时

请求有默认超时（10 秒）。后端慢的时候页面会卡住，建议后端接口保持快速，
或把慢操作放后台（用爻语的 `启采`）。

## 八、页面存储（跨页面共享）

爻页有**全局存储**，页面之间共享数据：

| 函数 | 作用 |
|---|---|
| `存(键, 值)` | 写入 |
| `载(键, 默认?)` | 读取 |
| `清(键?)` | 清除（不传键则全清） |

```yao-fragment
注 登录页存令牌
行 存("令牌", "abc123")
行 存("用户名", "张三")

注 其他页面读
"欢迎，" + 载("用户名", "访客") 归 问候
```

**存储是进程内的**（不落盘），浏览器关掉就没了。要持久化得靠后端。

## 九、常见问题

### 9.1 中文显示成方块

在**离屏渲染**（`--离屏`）里出现方块，说明找不到中文字体。

浏览器已内置字体查找逻辑：按顺序查 `%WINDIR%\Fonts` 下的
`msyhbd.ttc → msyh.ttc → simhei.ttf → simsun.ttc → Deng.ttf`。

如果都找不到（极精简系统），装一个中文字体即可。

### 9.2 页面空白 / 元素不显示

按这个顺序查：

1. **`--检` 有没有语法错误** → 语法错的话整个页面不渲染
2. **`--结构` 看盒子树** → 元素在但宽度为 0 通常是没有 `宽` 且内容为空
3. **看状态栏的「元素 N 个」** → N 很小说明条件渲染没命中

### 9.3 点击按钮没反应

爻页的事件限制：

- **只有 `钮` 有点击事件**，`横`/`竖`/`层` 不支持 `点`
- 事件体里**不能有纯表达式语句**，返回值用不上的调用要写 `行 函数()`
- 事件里改状态必须用 `置`（`置 计数 计数 + 1`）或「表达式 易 状态名」

```text
注 ✗ 错：容器不能点
横 点 【 置 计数 1 】 【 文 "点我" 】

注 ✓ 对：用按钮
钮 "点我" 点 【 置 计数 1 】
```

### 9.4 输入框打字没反应

`输` 后面必须跟**状态名**：

```yao-fragment
"" 态 账号

注 ✓ 对
输 账号 宽 300

注 ✗ 错：不能跟字面量，也不能加 归
输 "" 宽 300
输 账号 归 账号 宽 300
```

### 9.5 「没有这个函数」

页面内函数（`匠`）**必须先定义后使用**，而且 `始` 块执行时函数还没注册。

```yao-fragment
注 ✗ 错：始 里调用了还没注册的函数
始 【 行 刷新() 】
匠 刷新() 【 回 1 】

注 ✓ 对：函数定义在始之前，且不在始里调用函数
匠 刷新() 【 回 1 】
始 【 置 提示 "就绪" 】
```

如果确实需要初始化时计算，用 `次` 定时器延后第一次执行。

### 9.6 页面刷新后数据没了

状态是**页面级**的，`跳` 到别的页面再回来会重建状态。
需要保留的数据用 `存()` 放全局存储。

### 9.7 内容超出窗口看不到

爻页**没有滚动容器**。内容超出窗口就看不到了。

解决办法：分页显示、减少内容、或把长列表放到多列布局里。

## 十、性能参考

| 场景 | 元素数 | 渲染耗时 |
|---|---|---|
| 简单表单 | 21 | ~10 ms |
| 论坛首页 | 46 | ~97 ms |
| 分拣监控总览 | 74 | ~50 ms |
| 大列表（200 行） | 800+ | 可能 >500 ms |

**渲染是全量的**，没有 diff。所以：

- 用 `次 2000 毫秒` 轮询时，元素太多会明显卡顿
- 列表超过 100 行时建议分页或只显示摘要

## 十一、调试技巧

### 11.1 用状态栏打日志

```yao-fragment
"进到这里了" 易 提示
```

比 `显()` 直观 —— 直接显示在窗口底部，不会跑到控制台。

### 11.2 先离屏渲染，再开窗口

改一次页面就开一次窗口比较慢。**先离屏看成图**：

```powershell
爻页\浏览器\爻页浏览器.exe --离屏 页面.页 build\调试.png 1000 760
```

看的满意了再开窗口。

### 11.3 用 `--结构` 查布局

元素位置不对时，看盒树比猜快得多：

```powershell
爻页\浏览器\爻页浏览器.exe --结构 页面.页 | Select-String "钮"
```

### 11.4 浏览器控制台

开发模式下，Python 进程的 stdout 就是控制台。
错误会打印完整堆栈，包括爻页源码的行列号。

## 十二、完整实战示例

一个从零开始的最小前后端：

### 12.1 后端（`后端.yao`）

```yao
"页面" 名 页面根

路("GET", "/页/:名", 节 (请) 【
  请.参["名"] 名 页名
  页面根 + "/" + 页名 + ".页" 名 路径
  判 【 在(路径) == 假 ⇒ 归 应(404, {}, "没有这个页面") 】
  归 应(200, { "Content-Type" ⇒ "text/plain; charset=utf-8" }, 读(路径))
】)

路("GET", "/api/问候", 节 (请) 【
  归 { "消息" ⇒ "你好，来自后端", "时间" ⇒ 今() }
】)

听(8800)
```

### 12.2 前端（`页面/首页.页`）

```yao-fragment
页 "我的应用" 【
  "" 态 消息
  "" 态 时间

  匠 刷新() 【
    抓("http://127.0.0.1:8800/api/问候") 归 响应
    判 取(响应, "码", 0) == 200 【
      真 ⇒ 【
        析(取字段(响应, "文", "{}")) 归 果
        取字段(果, "消息") 易 消息
        取字段(果, "时间") 易 时间
      】
      它 ⇒ "后端连不上" 易 消息
    】
    回 1
  】

  始 【
    置 消息 "点按钮刷新"
  】

  竖 填 30 缝 16 底 "#0a0f1a" 【
    文 "我的应用" 大 24 粗 色 "#7ee787"
    文 消息 大 14 色 "#e2e8f0"
    文 时间 大 11 色 "#94a3b8"
    钮 "刷新" 点 【 行 刷新() 】 底 "#7ee787" 色 "#06210f" 圆 6 大 14
  】
】
```

### 12.3 运行

```powershell
# 1. 起后端
爻语\解释器\exe\yao.exe 跑 后端.yao

# 2. 起浏览器
爻页\浏览器\爻页浏览器.exe http://127.0.0.1:8800/页/首页
```

点「刷新」→ 页面显示后端返回的消息和时间。
