# 爻页（YaoPage）语言手册

> 一门**专门描述界面**的前端语言，配一个从零实现的浏览器。
> **不生成 HTML，不用 CSS，不执行 JavaScript** —— 元素、样式、布局、事件、渲染
> 全部是爻页自己的。
>
> 版本 0.1.0 ｜ 文件后缀 `.页` ｜ 实现：Python 3.11 标准库 tkinter ｜ 入口 `爻页\浏览器\爻页浏览器.exe`

---


> **运行方式**（两种都行，exe 不需要装 Python）
>
> ```powershell
> 爻语\解释器\exe\yao.exe 程序.yao      # 推荐：单文件，无依赖
> 爻语\解释器\exe\yao.exe 程序.yao        # 备选：开发时用，功能更全
> ```
>
> **能力差异**：`yao.exe`（C 版）支持语言核心语法、75 个内置函数里的 48 个，
> 但**不含** Web 服务、MQTT、Modbus TCP。做网页后端或工业物联请用 Python 版。
> 完整对照见 [手册.md](手册.md#解释器版本对照)。

## 1. 它是什么

爻页是一门前端语言。写一个 `.页` 文件，用爻页浏览器打开，就能看到一个原生窗口里的界面。

| | 传统 Web | 爻页 |
|---|---|---|
| 结构 | HTML 标签 | 爻页元素：`竖 横 层 文 钮 输 图 线 空 列` |
| 样式 | CSS 属性 | 爻页修饰：`填 缝 大 色 底 圆 边 齐` |
| 逻辑 | JavaScript | `态` 状态 + `置` 修改 + `点` 事件 + `判` 分支 |
| 布局 | 浏览器 flex/grid | 爻页盒模型引擎（自己写） |
| 渲染 | 浏览器内核 | 爻页 Canvas 渲染器（自己写） |
| 运行环境 | Chrome/Firefox | 爻页浏览器（tkinter 原生窗口） |

**整个技术栈没有一行 HTML/CSS/JS。**

它不是只能做静态页面：能取后端数据（`抓`）、调接口（`调`）、跳转（`跳`）、
按数据重复渲染（`列`）。本仓库的论坛前端就是爻页写的。

## 2. 运行与浏览器

### 2.1 启动

```powershell
# 打开浏览器（默认欢迎页）
爻页\浏览器\爻页浏览器.exe

# 打开指定页面
爻页\浏览器\爻页浏览器.exe 语言\爻页\示例\计数器.页

# 只做语法检查
爻页\浏览器\爻页浏览器.exe --检 页面.页

# 打印布局盒树（调试用）
爻页\浏览器\爻页浏览器.exe --结构 页面.页

# 无头渲染成 PNG（不需要开窗口）
爻页\浏览器\爻页浏览器.exe --离屏 页面.页 输出.png 900 700
```

### 2.2 浏览器窗口

```
┌──────────────────────────────────────────────────────────┐
│  ←  →  ↻  [ 爻页/示例/计数器.页            ] 打开 选文件 │  地址栏
├──────────────────────────────────────────────────────────┤
│                                                          │
│                    页面渲染区（Canvas）                    │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 就绪 · 计数器 · 元素 17 个 · 状态 1 个 · 渲染 1.2 ms        │  状态栏
└──────────────────────────────────────────────────────────┘
```

| 控件 | 作用 |
|---|---|
| **地址栏** | 输入 `.页` 路径（相对项目根），回车打开 |
| **← →** | 前进 / 后退（有历史记录） |
| **↻** | 重新解析并重绘 |
| **打开 / 选文件** | 文件对话框选择 |
| **状态栏** | 页面标题、元素数、状态数、渲染耗时、错误信息 |

快捷键：

| 键 | 作用 |
|---|---|
| `Ctrl + L` | 聚焦地址栏 |
| `F5` | 重新载入 |

**出错不会崩**：解析或运行出错时，渲染区中央显示中文错误（含行列号），
状态栏同步提示。

### 2.3 带参数打开

地址栏可以传参数，页面里当作状态读：

```
贴子.页#号=1&页=2
```

页面里声明 `0 态 号` 后，`号` 的值就是字符串 `"1"`。

## 3. 第一个页面

```
页 "你好爻页" 【
  竖 填 30 缝 14 底 "#0b1020" 【
    文 "你好，爻页" 大 32 粗 色 "#7ee787" 齐 中
    文 "这是一个原生窗口，不是网页。" 大 14 色 "#94a3b8" 齐 中
  】 圆 16 边 1 边色 "#24304d"
】
```

保存为 `你好.页`，然后：

```powershell
爻页\浏览器\爻页浏览器.exe 你好.页
```

**读法**：

- `页 "标题" 【 … 】` —— 页面根，一个文件只能有一个根容器
- `竖` —— 纵向容器（子元素自上而下）
- `填 30` —— 内边距 30
- `文 "你好，爻页"` —— 一段文字
- `大 32 粗 色 "#7ee787" 齐 中` —— 字号 32、加粗、绿色、居中

## 4. 词法

### 4.1 注释

```
注 单行注释（注 后面必须跟空格或行尾）
注【 块注释，可以嵌套 注【 内层 】 结束 】
```

> `注` 后面紧跟字符时会当成标识符的一部分，所以 `注册`、`注意` 可以作状态名。

### 4.2 标识符

首字符：汉字 / 字母 / `_`；后续可含数字。
**不能与关键字同名，也不能以关键字结尾**。

```
0 态 计数          ✓
0 态 次数          ✓
0 态 步            ✗ 「步」是关键字
0 态 单步          ✗ 以关键字「步」结尾
```

### 4.3 字面量

| 类型 | 写法 |
|---|---|
| 数 | `42`、`3.14`、`-7` |
| 字 | `"文本"`、`'文本'` |
| 真/假 | `真`、`假` |
| 空值 | `空值`（注意：`空` 是占位元素，空值写作 `空值`） |
| 列 | `[1, 2, 3]` |
| 表 | `{ "键" ⇒ 值 }` |

### 4.4 符号

块用 `【 】`，箭号 `⇒`，表用 `{ }`，列用 `[ ]`。
全角符号会自动转半角（`（ ）`、`，`、`：` 等）。

## 5. 元素

### 5.1 容器（3 种）

| 元素 | 布局方式 | 例子 |
|---|---|---|
| `竖` | 子元素自上而下 | `竖 填 20 缝 10 【 … 】` |
| `横` | 子元素自左而右 | `横 缝 8 【 … 】` |
| `层` | 子是叠放的，后声明的在上 | `层 【 … 】` |

容器默认宽度撑满父容器（竖）或由内容决定（横/层）。

### 5.2 内容元素（4 种：文 钮 输 图）

| 元素 | 写法 | 说明 |
|---|---|---|
| `文` | `文 "文本"` 或 `文 表达式` | 文本，超宽自动折行 |
| `钮` | `钮 "标签"` 或 `钮 表达式` | 按钮，可带 `点` 事件 |
| `输` | `输 状态名` | 输入框，与状态双向绑定 |
| `图` | `图 "路径.png"` | 图片，缺失时画占位框 |
| `线` | `线` | 分割线 |

### 5.3 占位（1 种）

| 元素 | 写法 | 说明 |
|---|---|---|
| `空` | `空 20` | 20px 高的空白（也可用 `底` 画色块） |

### 5.4 列表（1 种）

```
列 项 于 数据源 【
  文 取字段(项, "标题")
】 缝 8
```

对数据源里**每一项**重复渲染块内的元素。

| 写法 | 说明 |
|---|---|
| `列 项 于 列` | `项` 绑定每次迭代的值 |
| `列 项 于 表` | 迭代表的值 |
| `… 缝 8` | 项之间间距 |
| `… 横排` | 横向排列（默认是竖向） |

迭代时额外提供两个变量：

- `项序` —— 当前下标（0 开始）
- `该项键` —— 表的键（列时等于下标）

## 6. 修饰（样式）

修饰写在元素内容之后，或容器的块**之前/之后**都可以。

### 6.1 盒子

| 修饰 | 值 | 说明 |
|---|---|---|
| `填` | 数 | 内边距 |
| `缝` | 数 | 子元素间距 |
| `宽` | 数 / `满` | 宽度，`满` 撑满父容器 |
| `高` | 数 | 高度 |

### 6.2 文字

| 修饰 | 值 | 说明 |
|---|---|---|
| `大` | 数 | 字号（默认 15） |
| `色` | 颜色 | 文字颜色（默认 `#e2e8f0`） |
| `粗` | 无 | 加粗 |
| `齐` | `左` / `中` / `右` | 对齐 |

### 6.3 外观

| 修饰 | 值 | 说明 |
|---|---|---|
| `底` | 颜色 | 背景色 |
| `圆` | 数 | 圆角半径 |
| `边` | 数 | 边框宽度 |
| `边色` | 颜色 | 边框颜色 |
| `悬底` | 颜色 | 鼠标悬停时的背景 |
| `手` | 无 | 鼠标变手型 |

### 6.4 行为

| 修饰 | 值 | 说明 |
|---|---|---|
| `隐` | 表达式 | 表达式为真时**隐藏且不占空间** |
| `横排` | 无 | 只用于 `列`，横向排列 |

### 6.5 颜色

支持：

- 十六进制：`"#7ee787"`、`"#0b1020"`
- 颜色名：`"red"`、`"white"`

### 6.6 一个样式齐全的例子

```
竖 填 24 缝 12 底 "#111827" 边 2 边色 "#7ee787" 圆 12 宽 400 【
  文 "标题" 大 22 粗 色 "#e2e8f0" 齐 中
  线 边色 "#24304d"
  钮 "点我" 底 "#7ee787" 色 "#06210f" 粗 圆 8 手 悬底 "#a7f3b9"
】 隐 假
```

## 7. 状态与事件

### 7.1 声明状态

```
0 态 计数
"" 态 昵称
空值 态 数据
```

**值在左**（与爻语一致）：先写初始值，再写 `态`，最后写名字。
状态只能声明在**页面顶层**，必须在根容器之前。

### 7.2 使用状态

在表达式里直接写名字：

```
文 "当前值：" + 串(计数)
文 "你好，" + 昵称
```

### 7.3 修改状态

```
置 计数 计数 + 1
置 昵称 ""
```

`置` 只能写在 `点` / `始` / `判` 的块里。修改后**整页重新求值、重新布局、重新绘制**。

### 7.4 点击事件

```
钮 "加一" 点 【 置 计数 计数 + 1 】
```

块里可以写多条语句：

```
钮 "重置" 点 【
  置 计数 0
  置 提示 "已重置"
  置 显示 假
】
```

### 7.5 页面初始化

```
始 【
  抓("http://127.0.0.1:8793/api/贴") 归 响应
  析(取字段(响应, "文")) 归 贴们
  "加载完成" 归 提示
】
```

页面加载时自动执行一次，用来取数据、初始化状态。

在 `始` 块里 `归` 可以**新建**变量（不必预先声明 `态`），这是唯一允许的地方。

### 7.6 调用后端

```
钮 "登录" 点 【
  调 "/api/登录" { "名" ⇒ 账号, "密码" ⇒ 密码 } 归 果
  判 取字段(果, "成") == 真 【
    真 ⇒ 置 提示 "登录成功"
    它 ⇒ 置 提示 取字段(果, "说明")
  】
】
```

`调` 会向后端发请求（默认指向 `http://127.0.0.1:8793`），返回解析后的 JSON 写进指定状态。

体里的键 `_令牌` 会被取出放进 `X-Token` 请求头（不发给后端）。

### 7.7 页面跳转

```
钮 "查看" 点 【 跳 "贴子.页#号=" + 串(取字段(贴, "号")) 】
```

路径可以是相对（相对当前页面所在目录）或绝对。`#` 后面是参数。

### 7.8 事件优先级与上下文

- 点击优先级：`层` 里**后声明**的元素优先（在最上层）
- `列` 展开的按钮被点击时，会自动恢复该项的绑定（`项`、`项序`、`该项键`）

## 8. 控制流

### 8.1 条件分支（语句位置）

```
判 计数 > 10 【
  真 ⇒ 置 提示 "太多了"
  它 ⇒ 置 提示 "还好"
】
```

臂体有多条语句时用**块**：

```
判 条件 【
  真 ⇒ 【
    置 甲 1
    置 乙 2
  】
  它 ⇒ 置 甲 0
】
```

### 8.2 条件渲染（元素位置）

```
判 已登录 【
  真 ⇒ 钮 "退出" 点 【 置 已登录 假 】
  它 ⇒ 钮 "登录" 点 【 跳 "登录.页" 】
】
```

只渲染被选中的那个元素，没选中的不占空间。

### 8.3 分支臂

| 臂 | 含义 |
|---|---|
| `真 ⇒ …` | 条件为真 |
| `假 ⇒ …` | 条件为假 |
| `它 ⇒ …` | 兜底（等同 else） |

## 9. 表达式与内置函数

### 9.1 运算符

| 类别 | 运算符 |
|---|---|
| 算术 | `+ - * / %` |
| 比较 | `== != < <= > >=` |
| 逻辑 | `且` `或` `非` |

`+` 对字符串是拼接（自动把另一边转成字符串）：

```
文 "共 " + 串(贴数) + " 贴"
文 "回复 " + 取字段(贴, "回复数")    注 数字自动转字
```

优先级（低 → 高）：

```
或 → 且 → 非 → 比较 → + - → * / % → 一元 - → 调用
```

### 9.2 内置函数（29 个）

| 名 | 签名 | 说明 |
|---|---|---|
| `串` | `串(值)` | 转字符串 |
| `数` | `数(值)` | 转数字（失败抛错） |
| `整` | `整(值)` | 取整 |
| `长` | `长(字\|列\|表)` | 长度 |

**字与列**

| 名 | 签名 | 说明 |
|---|---|---|
| `切` | `切(值, 起, 止?)` | 子串 / 子列 |
| `含` | `含(值, 子)` | 包含 |
| `连` | `连(列, 分隔?)` | 连接成字 |
| `拆` | `拆(字, 分隔?)` | 拆成列 |
| `截断` | `截断(字, 长?)` | 截断加省略号 |

**集合**

| 名 | 签名 | 说明 |

| `有` | `有(表, 键)` | 键是否存在 |

**数学**

| 名 | 签名 | 说明 |
|---|---|---|
| `舍` | `舍(数, 位?)` | 四舍五入到 N 位小数 |
| `绝` | `绝(数)` | 绝对值 |

**时间**

| 名 | 签名 | 说明 |
|---|---|---|
| `今` | `今()` | 当前时间字符串 `YYYY-MM-DD HH:MM:SS` |

**JSON 与 HTTP**

| 名 | 签名 | 说明 |
|---|---|---|
| `析` | `析(文)` | **解析 JSON** → 表 / 列 |
| `构` | `构(值)` | **生成 JSON** |
| `抓` | `抓(网址)` | **GET 请求**，返回 `{码, 文, 头}` |
| `请求` | `请求(网址, {法, 体, 头}?)` | **任意 HTTP 方法**，返回 `{码, 文, 头}` |

**页面存储**（跨页面共享）

| 名 | 签名 | 说明 |
|---|---|---|
| `存` | `存(键, 值)` | 写入全局存储 |
| `载` | `载(键, 默认?)` | 读取全局存储 |
| `清` | `清(键?)` | 清除（不传键则全清） |

> `连`/`拆` 不叫 `并`/`分`，因为 `并` 与逻辑关键字冲突。
>
> `请求` 会自动带上登录令牌（`X-Token` 头），用于需要鉴权的后端接口。

### 9.3 JSON 处理

`抓` 返回的 `文` 是**原始 JSON 字符串**，要先用 `析` 解析：

```
抓("http://127.0.0.1:8793/api/贴") 归 响应
析(取字段(响应, "文")) 归 贴们         注 现在是列
列 贴 于 贴们 【
  文 取字段(贴, "标题")
】 缝 8
```

## 10. 布局引擎

爻页不用 flex/grid，是自己实现的简单盒模型。

### 10.1 盒模型

```
┌──────────── 盒子外框 ────────────┐
│  填（内边距）                     │
│   ┌──────── 内容区 ────────┐     │
│   │                        │     │
│   │     子元素 / 文本        │     │
│   │                        │     │
│   └────────────────────────┘     │
│                                  │
└──────────────────────────────────┘
```

### 10.2 尺寸规则

| 元素 | 宽度 | 高度 |
|---|---|---|
| `竖` | 默认撑满父容器 | 由内容决定 |
| `横` | 由内容决定 | 由内容决定 |
| `层` | 由内容决定 | 最高子元素 |
| `文` | 按文本（`齐 中/右` 时撑满） | 行数 × 字号 × 1.45 |
| `钮` | 文本宽 + 36 | 字号 × 1.5 + 20 |
| `输` | 默认 200 | 字号 × 1.5 + 12 |
| `线` | 撑满 | 1（或 `边` 指定） |
| `空` | 撑满 | 表达式值 |

显式 `宽` / `高` 优先于以上规则。`宽 满` = 撑满父容器的内容宽。

### 10.3 排列

**竖容器**

```
上填 + 子1高 + 缝 + 子2高 + 缝 + 子3高 + 下填
```

**横容器**

```
左填 + 子1宽 + 缝 + 子2宽 + 下填
```

**层容器**：所有子元素叠在左上角，高度取最高者。

### 10.4 文本折行

按字符宽度估算：

- 中文/全角字符：`1.0 × 字号`
- ASCII 字符：`0.55 × 字号`

累计超过可用宽度时换行。优先在空格处断行，中文可在任意字符处断。

### 10.5 坐标约定

**布局产出的 `x/y` 是相对父容器**的；渲染和命中测试时**逐层累加**得到绝对坐标。

```
根 (0,0)
└─ 竖 (24,24)
   └─ 横 (24, 24+89)
      └─ 登录按钮 (158, 0)  → 绝对 (181, 22)
```

### 10.6 对齐

- `齐 中` 在竖容器里：子元素按自身宽度居中
- `齐 中` 在文上：文字在盒子内居中（盒子撑满可用宽）
- `齐 右`：靠右

## 11. 事件系统

### 11.1 鼠标

| 事件 | 触发 | 处理 |
|---|---|---|
| 点击 | 左键按下并释放 | 执行该元素的 `点` 块 |
| 悬停 | 鼠标进入元素 | 用 `悬底` 换背景，`手` 换光标 |
| 窗口缩放 | 窗口大小改变 | 整页重新布局重绘 |

### 11.2 键盘输入

点击 `输` 元素后取得焦点，之后键盘输入写入绑定的状态：

- 普通字符：追加到末尾
- `BackSpace`：删最后一个字符

> **限制**：不支持光标移动、选中、粘贴。中文输入依赖 IME 是否走 `WM_CHAR`。

### 11.3 命中测试

鼠标点击时，从根盒递归向下查找，找到坐标所在的 `钮` / `输` 盒：

- 先查子，再查自己（`层` 里后声明的优先）
- **逐层累加父偏移**后与鼠标绝对坐标比较

## 12. 浏览器架构

### 12.1 数据流

```
  .页 文件
     │
     ▼
  词法.py      → 词（关键字/字面量/符号/块）
     │
     ▼
  语法.py      → 抽象节点（页面/状态/元素/表达式）
     │
     ▼
  求值.py      → 执行「始」块，初始化状态
     │
     ▼
  布局.py      → 盒树（每个盒有 x/y/宽/高/样式）
     │
     ├─────────────┐
     ▼             ▼
  渲染.py       事件系统
  Canvas 绘制    命中测试 → 执行点块 → 重新求值
     │
     ▼
  浏览器.py   窗口外壳（地址栏/历史/状态栏）
```

### 12.2 源码结构

```
爻页/解释器/python版/
├─ __init__.py     包信息（版本、名称、后缀）
├─ __main__.py     命令行入口
├─ 错误.py          6 种错误类型
├─ 词法.py          词法分析（58 个保留字）
├─ 语法.py          递归下降 + Pratt 表达式 → 抽象节点
├─ 求值.py          状态管理、表达式求值、15 个内置函数
├─ 布局.py          盒模型引擎 + 命中测试
├─ 渲染.py          tkinter Canvas 绘制
├─ 浏览器.py        窗口外壳、事件分发、HTTP 调用
├─ 离屏.py          无头渲染（PNG 导出 + 盒树摘要）
├─ 示例/            .页 示例（4 个）
└─ 测试/            pytest（85 个用例）
```

### 12.3 各模块职责

| 文件 | 输入 | 输出 | 核心函数 |
|---|---|---|---|
| `词法.py` | 源码字符串 | `词[]` | `切分()` |
| `语法.py` | `词[]` | `页面` 节点 | `分析文本()` |
| `求值.py` | 节点 + 状态 | 值 | `求值器.求值()` |
| `布局.py` | 页面节点 + 视口尺寸 | 盒树 | `布局()` |
| `渲染.py` | 盒树 | Canvas 图元 | `画布渲染器.渲染()` |
| `浏览器.py` | — | 窗口 | `浏览器.打开()` |

### 12.4 重绘流程

```
用户点击
   ↓
命中测试找到盒
   ↓
执行盒的「点」块（可能修改状态）
   ↓
整页重新求值 → 重新布局 → 重新绘制
```

每次重绘都是**全量**的，没有 diff。实测论坛首页（46 个元素）约 **97ms**，够用。

### 页面内函数（`匠`）

爻页支持在页面里定义函数，用于封装重复逻辑。**注意：函数体只支持有限语句**
（`置` / `发` / `判` / `跳` / `调` / `回` / `行`，以及「表达式 归/易 状态名」），
**不支持 `循` 和 `列` 循环**。

```
页 "示例" 【
  0 态 计数
  0 态 结果

  匠 加倍(值) 【
    回 值 * 2
  】

  匠 刷新() 【
    置 结果 加倍(计数)
    回 1
  】

  竖 填 20 【
    钮 "加一并算" 点 【
      置 计数 计数 + 1
      行 刷新()
    】
    文 "计数 = " + 串(计数) + "，加倍 = " + 串(结果) 大 14
  】
】
```

**限制一：不能循环**。爻页的 `列` 是**元素渲染语句**（只能在元素位置用），
`循` 属于爻语而非爻页。需要遍历数据时，在元素位置用 `列`，或让后端返回已算好的结果。

**限制三：`始` 块里不能调用页面内函数**。`始` 执行时函数还没注册。
需要初始化计算时，用 `次` 定时器延后第一次执行，或直接写在状态初值里。

**限制二：不能有纯表达式语句**。每个表达式都必须「落到一个状态上」：

```
匠 对() 【
  行 存("k", 1)         注 ✓ 行前缀 = 只执行不取值
  1 + 2 归 结果         注 ✓ 落到状态
  存("k", 1)            注 ✗ 法误：这里需要「归 状态名」或「易 状态名」
  回 1
】
```

## 已知限制

- 只有三种容器，没有浮动、绝对定位、网格
- 文本折行用字符宽度估算，不是真实字体度量（不同字体可能差几像素）
- 图片需要 Pillow，缺失时画占位框
- 输入框只支持末尾追加和退格，不支持光标移动/选中/粘贴
- 没有动画、没有过渡
- 每次操作全量重绘（大页面可能变慢）
- 单窗口，不支持多标签
