# 爻页（YaoPage）

**界面描述语言** + **自带渲染引擎的浏览器**。不生成 HTML/CSS/JS ——
词法、语法、布局、渲染全部用 Python 标准库 tkinter 从零实现。

```
爻页/
├── 文档/              ← 语法参考、手册、使用说明
├── 解释器/            ← 语言内核（词法/语法/布局/渲染）
│   ├── python版/
│   └── exe/
├── 浏览器/            ← 能运行 .页 程序的图形界面程序
└── 示例/              ← 示例页面
```

---

## 它是什么

传统前端要写三种语言：

| 用 HTML/CSS/JS | 用爻页（一种语言） |
|---|---|
| `<div style="padding:20px"><p>你好</p></div>` | `竖 填 20 【 文 "你好" 】` |
| `.box { background: #111 }` | `底 "#111"` |
| `let n = 0` | `0 态 n` |
| `onclick="n++"` | `钮 "加" 点 【 置 n n + 1 】` |

**58 个保留字**：4 结构 + 8 元素 + 19 修饰 + 16 语句 + 逻辑与对齐值。

### exe/ —— 可执行文件

爻页**没有独立的解释器 exe** —— 解释器被内嵌进浏览器程序里了。
运行 `.页` 程序请用 `浏览器/爻页浏览器.exe`。

## 浏览器

`浏览器/爻页浏览器.exe` —— **15 MB 单文件，不需要 Python，可直接拷给别人双击运行**。

```powershell
爻页浏览器.exe 页面.页                     # 打开页面
爻页浏览器.exe http://host:port/页/名      # 打开远程页面
爻页浏览器.exe --检 页面.页                # 语法检查
爻页浏览器.exe --离屏 页面.页 出.png       # 渲染成图片
```

**在无 Python 环境下验证 6/6 通过**：版本、语法检查、离屏渲染、图形窗口、路径解析、中文显示。

详细用法见 [文档/浏览器使用说明.md](文档/浏览器使用说明.md)。

## 能力与限制

### 能做

- 3 种容器（竖/横/层）+ 8 种元素
- 19 种修饰（内边距/间距/圆角/边框/字号/颜色/对齐…）
- 状态自动重绘（改了状态界面自动更新）
- 输入框双向绑定
- 点击事件、定时器、页面跳转
- HTTP 请求（**自动带登录令牌**）
- 跨页面全局存储

### 不能做

| 限制 | 说明 |
|---|---|
| 无循环语句 | 函数体不支持 `循`；遍历数据用元素位置的 `列` |
| 无纯表达式语句 | 函数里每个表达式必须「落到状态上」或加 `行` 前缀 |
| `始` 块不能调页面函数 | 执行时机早于函数注册 |
| 全量重绘 | 没有 diff，元素多会慢（46 元素约 97ms） |
| 无滚动容器 | 内容超出窗口看不到 |
| 无动画 | 没有过渡/动画 API |
| 只有 Windows 的 exe | 其他平台需重新打包 |

