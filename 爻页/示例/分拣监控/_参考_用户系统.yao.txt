注 ============================================================
注 用户系统：注册 / 登录 / 会话 / 多角色权限
注
注 角色：
注   管理员 admin   —— 全部权限：用户管理、物联配置、参数、启停
注   操作员 operator —— 可启停设备、调速、确认告警、看数据；不能改参数和用户
注   访客 viewer    —— 只能看，不能做任何操作
注
注 密码用散列存储（不存明文）。
注 会话用令牌（存在内存 + 落盘），前端把令牌放 X-Token 头。

注 ============ 用户库 ============

匠 空用户库() 【
  归 {
    "用户" ⇒ {},
    "下一号" ⇒ 1,
    "会话" ⇒ {}
  }
】

匠 读用户库() 【
  判 【 在(用户库路径) == 假 ⇒ 归 空用户库() 它 ⇒ 空 】
  试 【
    析(读(用户库路径)) 名 库
    判 【
      型(库) != "表" ⇒ 归 空用户库()
      含(库, "用户") == 假 ⇒ 归 空用户库()
      它 ⇒ 归 库
    】
  】 捕 误 【
    归 空用户库()
  】
】

匠 写用户库(库) 【
  写(用户库路径, 构(库))
  归 空
】

注 首次启动：创建默认管理员
匠 确保管理员(库) 【
  0 名 有管理员
  键集(库["用户"]) 名 键们
  遍 键 于 键们 【
    取(库["用户"], 键, {}) 名 用
    判 【
      取(用, "角色", "") == "admin" ⇒ 1 易 有管理员
      它 ⇒ 空
    】
  】
  判 【
    有管理员 == 0 ⇒ 【
      库["下一号"] + 1 易 库["下一号"]
      {
        "号" ⇒ 库["下一号"],
        "账号" ⇒ "admin",
        "密码" ⇒ 散列("admin123"),
        "名" ⇒ "系统管理员",
        "角色" ⇒ "admin",
        "启用" ⇒ 真,
        "建立" ⇒ 今(),
        "最后登录" ⇒ ""
      } 名 管
      管 易 库["用户"]["admin"]
      写用户库(库)
      显("已创建默认管理员：admin / admin123")
      归 管
    】
    它 ⇒ 归 空
  】
】

注 ============ 会话 ============

注 会话表：令牌 → { 账号, 角色, 建立, 过期 }
{} 名 会话表

匠 建会话(库, 账号, 角色) 【
  散列(账号 + 串(滴()) + 随机字(16)) 名 令牌
  {
    "账号" ⇒ 账号,
    "角色" ⇒ 角色,
    "建立" ⇒ 滴(),
    "过期" ⇒ 滴() + 8 * 3600 * 1000
  } 名 会话
  会话 易 会话表[令牌]
  令牌 易 库["会话"][令牌]
  写用户库(库)
  归 令牌
】

匠 查会话(令牌) 【
  判 【
    令牌 == 空 或 令牌 == "" ⇒ 归 空
    它 ⇒ 空
  】
  取(会话表, 令牌, 空) 名 会话
  判 【
    会话 == 空 ⇒ 【
      注 内存里没有，试从磁盘恢复（重启后仍有效）
      读用户库() 名 库
      取(库["会话"], 令牌, 空) 名 存会话
      判 【
        存会话 == 空 ⇒ 归 空
        它 ⇒ 存会话 易 会话
      】
      会话 易 会话表[令牌]
    】
    它 ⇒ 空
  】
  注 过期检查
  判 【
    滴() > 取(会话, "过期", 0) ⇒ 【
      删(会话表, 令牌)
      归 空
    】
    它 ⇒ 空
  】
  归 会话
】

匠 销会话(令牌) 【
  判 【 令牌 == 空 ⇒ 归 空 它 ⇒ 空 】
  删(会话表, 令牌)
  读用户库() 名 库
  删(库["会话"], 令牌)
  写用户库(库)
  归 空
】

注 ============ 权限判定 ============

匠 有权(会话, 权限) 【
  判 【 会话 == 空 ⇒ 归 假 它 ⇒ 空 】
  取(会话, "角色", "viewer") 名 角色
  取(角色权限, 角色, []) 名 权限们
  归 含(权限们, 权限)
】

注 从请求里取会话（令牌放 X-Token 头，也支持 ?令牌=）
匠 请求会话(请) 【
  取(请.头, "x-token", "") 名 头令牌
  判 【
    头令牌 != "" ⇒ 归 查会话(头令牌)
    它 ⇒ 空
  】
  取(请.参, "令牌", "") 名 参令牌
  判 【
    参令牌 != "" ⇒ 归 查会话(参令牌)
    它 ⇒ 归 空
  】
】

注 检查权限，不够就返回 403 的响应；够了返回 空
匠 需权限(请, 权限) 【
  请求会话(请) 名 会话
  判 【
    会话 == 空 ⇒ 归 应(401, { "Content-Type" ⇒ "application/json; charset=utf-8" }, { "错" ⇒ "请先登录", "未登录" ⇒ 真 })
    它 ⇒ 空
  】
  判 【
    有权(会话, 权限) == 假 ⇒ 归 应(403, { "Content-Type" ⇒ "application/json; charset=utf-8" }, { "错" ⇒ "权限不足：需要「" + 权限 + "」", "无权限" ⇒ 真 })
    它 ⇒ 归 空
  】
】

注 ============ 用户操作 ============

匠 账号合法(账号) 【
  判 【 长(账号) < 3 ⇒ 归 "账号至少 3 个字符" 它 ⇒ 空 】
  判 【 长(账号) > 30 ⇒ 归 "账号不能超过 30 个字符" 它 ⇒ 空 】
  遍 字 于 拆(账号, "") 【
    判 【
      含("abcdefghijklmnopqrstuvwxyz0123456789_", 字) ⇒ 空
      它 ⇒ 归 "账号只能用小写字母、数字、下划线"
    】
  】
  归 空
】

匠 注册用户(库, 账号, 密码, 显示名, 角色) 【
  账号合法(账号) 名 错1
  判 【 错1 != 空 ⇒ 归 { "成" ⇒ 假, "错" ⇒ 错1 } 它 ⇒ 空 】
  判 【 长(密码) < 6 ⇒ 归 { "成" ⇒ 假, "错" ⇒ "密码至少 6 个字符" } 它 ⇒ 空 】
  判 【 含(库["用户"], 账号) ⇒ 归 { "成" ⇒ 假, "错" ⇒ "这个账号已存在" } 它 ⇒ 空 】
  判 【
    含(["admin", "operator", "viewer"], 角色) ⇒ 空
    它 ⇒ 归 { "成" ⇒ 假, "错" ⇒ "角色只能是管理员/操作员/访客" }
  】

  库["下一号"] + 1 易 库["下一号"]
  {
    "号" ⇒ 库["下一号"],
    "账号" ⇒ 账号,
    "密码" ⇒ 散列(密码),
    "名" ⇒ 显示名,
    "角色" ⇒ 角色,
    "启用" ⇒ 真,
    "建立" ⇒ 今(),
    "最后登录" ⇒ ""
  } 名 新用户

  注 没给显示名就用账号
  判 【
    显示名 == "" ⇒ 账号 易 新用户["名"]
    它 ⇒ 空
  】

  新用户 易 库["用户"][账号]
  归 { "成" ⇒ 真, "用户" ⇒ 新用户 }
】

匠 验证登录(库, 账号, 密码) 【
  取(库["用户"], 账号, 空) 名 用
  判 【 用 == 空 ⇒ 归 { "成" ⇒ 假, "错" ⇒ "账号或密码错误" } 它 ⇒ 空 】
  判 【
    取(用, "密码", "") != 散列(密码) ⇒ 归 { "成" ⇒ 假, "错" ⇒ "账号或密码错误" }
    它 ⇒ 空
  】
  判 【
    取(用, "启用", 真) == 假 ⇒ 归 { "成" ⇒ 假, "错" ⇒ "这个账号已被禁用" }
    它 ⇒ 空
  】
  今() 易 用["最后登录"]
  归 { "成" ⇒ 真, "用户" ⇒ 用 }
】

匠 公开用户(用) 【
  归 {
    "号" ⇒ 取(用, "号", 0),
    "账号" ⇒ 取(用, "账号", ""),
    "名" ⇒ 取(用, "名", ""),
    "角色" ⇒ 取(用, "角色", "viewer"),
    "角色名" ⇒ 取(角色中文, 取(用, "角色", "viewer"), "访客"),
    "启用" ⇒ 取(用, "启用", 真),
    "建立" ⇒ 取(用, "建立", ""),
    "最后登录" ⇒ 取(用, "最后登录", "")
  }
】
