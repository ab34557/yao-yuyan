注 ============================================================
注 物联服务管理：启动 / 关闭 / 重启 MQTT 与 Modbus 连接
注
注 这是「上位机」的核心运维能力：
注   · 查看 MQTT / Modbus 连接状态
注   · 配置设备地址、端口、采集频率
注   · 启动 / 停止 / 重启采集服务
注   · 手动测试连通性
注
注 状态机：stopped → starting → running → stopping → stopped
注         任何状态都可以 → error
注 ============================================================

注 ============ 配置持久化 ============

匠 读物联配置() 【
  判 【 在(物联配置路径) == 假 ⇒ 归 物联配置 它 ⇒ 空 】
  试 【
    析(读(物联配置路径)) 名 盘配置
    判 【
      型(盘配置) != "表" ⇒ 归 物联配置
      它 ⇒ 归 盘配置
    】
  】 捕 误 【
    归 物联配置
  】
】

匠 写物联配置(配置) 【
  写(物联配置路径, 构(配置))
  归 空
】

注 ============ 状态查询 ============

匠 物联概况() 【
  归 {
    "MQTT" ⇒ 物联状态["MQTT"],

    "采集" ⇒ 物联状态["采集"],

    "配置" ⇒ 物联配置,
    "采集线程号" ⇒ 采集号,

  }
】

注 ============ 启停控制 ============

注 启动采集：如果已经在跑，先停再起
匠 启动物联() 【
  注 先停掉已有的
  判 【
    采集号 != 0 ⇒ 【
      试 【 停采(采集号) 】 捕 误 【 空 】
      0 易 采集号
    】
    它 ⇒ 空
  】

  "启动中" 易 物联状态["采集"]["状态"]
  "未连接" 易 物联状态["MQTT"]["状态"]
  "未连接" 易 物联状态["Modbus"]["状态"]
  今() 易 物联状态["启动时间"]

  注 启动采集线程
  试 【
    启采(采集循环) 名 结果
    取(结果, "号", 0) 易 采集号
    "运行中" 易 物联状态["采集"]["状态"]
    "重连中" 易 物联状态["MQTT"]["状态"]
    归 { "成" ⇒ 真, "说明" ⇒ "采集服务已启动" }
  】 捕 误 【
    "出错" 易 物联状态["采集"]["状态"]
    取(误, "说明", "未知错误") 易 物联状态["采集"]["最后错"]
    归 { "成" ⇒ 假, "错" ⇒ 取(误, "说明", "启动失败") }
  】
】

注 停止采集
匠 停止物联() 【
  判 【
    采集号 == 0 ⇒ 归 { "成" ⇒ 真, "说明" ⇒ "本来就没在跑" }
    它 ⇒ 空
  】
  "停止中" 易 物联状态["采集"]["状态"]
  试 【
    停采(采集号)
    0 易 采集号
    "已停止" 易 物联状态["采集"]["状态"]
    "已停止" 易 物联状态["MQTT"]["状态"]
    "已停止" 易 物联状态["Modbus"]["状态"]
    注 断开 MQTT 连接
    判 【
      mqtt句柄 != 0 ⇒ 【
        试 【 离联(mqtt句柄) 】 捕 误 【 空 】
        0 易 mqtt句柄
      】
      它 ⇒ 空
    】
    归 { "成" ⇒ 真, "说明" ⇒ "采集服务已停止" }
  】 捕 误 【
    "出错" 易 物联状态["采集"]["状态"]
    归 { "成" ⇒ 假, "错" ⇒ 取(误, "说明", "停止失败") }
  】
】

注 重启
匠 重启物联() 【
  停止物联() 名 _停果
  眠(0.5)
  启动物联() 名 起果
  归 起果
】

注 测试 MQTT 连通性（不影响正在跑的服务）
匠 测MQTT(配置) 【
  联(配置["mqtt主机"], 配置["mqtt端口"], "测-" + 随机字(6), 3) 名 连
  判 【
    连["号"] == 0 ⇒ 归 { "成" ⇒ 假, "错" ⇒ 连["错"] }
    它 ⇒ 空
  】
  订(连["号"], 配置["mqtt主题"]) 名 订果
  离联(连["号"])
  判 【
    订果["成"] ⇒ 归 { "成" ⇒ 真, "说明" ⇒ "MQTT 连接与订阅正常" }
    它 ⇒ 归 { "成" ⇒ 假, "错" ⇒ 订果["错"] }
  】
】

注 测试 Modbus 连通性
匠 测Modbus(配置) 【
  读寄(配置["modbus主机"], 配置["modbus端口"], 配置["modbus从站"], 0, 4, 3) 名 读
  判 【
    读["错"] != "" ⇒ 归 { "成" ⇒ 假, "错" ⇒ 读["错"] }
    它 ⇒ 归 { "成" ⇒ 真, "说明" ⇒ "Modbus 读到 4 个寄存器：" + 串(读["值们"]) }
  】
】
