注 ============ OEE 计算 ============
注
注 简化版 OEE（单台分拣线）：
注   可用率 = 实际运行时间 / 总时间
注   性能率 = 实际产量 / 理论产能（理论产能 = 速度 × 时间 × 每米件数）
注   质量率 = 正确分拣数 / 总分拣数 = 识别率（近似）
注
注 每米件数按 2 件/米估算。

匠 算OEE() 【
  判 【 长(分析历史) < 2 ⇒ 归 空 它 ⇒ 空 】

  取(分析历史, 0, {}) 名 首
  取(分析历史, 长(分析历史) - 1, {}) 名 尾

  取(尾, "时", 0) - 取(首, "时", 0) 名 毫秒差
  判 【 毫秒差 <= 0 ⇒ 归 空 它 ⇒ 空 】
  毫秒差 / 1000 名 秒差

  取(尾, "运行秒", 0) - 取(首, "运行秒", 0) 名 运行差
  取(尾, "到达", 0) - 取(首, "到达", 0) 名 产量差
  取(尾, "出货", 0) - 取(首, "出货", 0) 名 出货差
  取(尾, "超重", 0) - 取(首, "超重", 0) 名 超重差
  取(尾, "识别率", 100) 名 识别率

  注 可用率
  判 【
    秒差 > 0 ⇒ 最小(1, 运行差 / 秒差) 名 可用率
    它 ⇒ 0 名 可用率
  】

  注 性能率：理论产能 = 速度(m/s) × 2件/m × 秒数
  取(尾, "速度", 1.5) 名 速度
  速度 * 2 * 秒差 名 理论产能
  判 【
    理论产能 > 0 ⇒ 最小(1, 产量差 / 理论产能) 名 性能率
    它 ⇒ 0 名 性能率
  】

  注 质量率：用识别率近似（识别对的就是质量合格的）
  识别率 / 100 名 质量率

  可用率 * 性能率 * 质量率 * 100 名 oee

  归 {
    "oee" ⇒ 舍(oee, 1),
    "可用率" ⇒ 舍(可用率 * 100, 1),
    "性能率" ⇒ 舍(性能率 * 100, 1),
    "质量率" ⇒ 舍(质量率 * 100, 1),
    "采样秒" ⇒ 舍(秒差, 0),
    "产量" ⇒ 产量差,
    "出货" ⇒ 出货差,
    "超重" ⇒ 超重差
  }
】

注 ============ 产量趋势（分桶聚合） ============

匠 算产量趋势(桶数) 【
  判 【 长(分析历史) < 2 ⇒ 归 [] 它 ⇒ 空 】
  长(分析历史) / 桶数 名 每桶
  判 【 每桶 < 1 ⇒ 1 易 每桶 它 ⇒ 空 】

  [] 名 结果
  0 名 i
  循 i < 桶数 【
    舍(i * 每桶, 0) 名 起
    数(起) 名 下标
    判 【
      下标 < 长(分析历史) ⇒ 【
        取(分析历史, 下标, {}) 名 点
        增(结果, 取(点, "到达", 0))
      】
      它 ⇒ 增(结果, 0)
    】
    i + 1 易 i
  】
  归 结果
】

注 ============ 节拍分析 ============

匠 算节拍() 【
  判 【 长(分析历史) < 2 ⇒ 归 空 它 ⇒ 空 】
  取(分析历史, 0, {}) 名 首
  取(分析历史, 长(分析历史) - 1, {}) 名 尾
  取(尾, "运行秒", 0) - 取(首, "运行秒", 0) 名 秒差
  取(尾, "出货", 0) - 取(首, "出货", 0) 名 出货差
  判 【
    出货差 > 0 且 秒差 > 0 ⇒ 【
      归 {
        "每件秒" ⇒ 舍(秒差 / 出货差, 2),
        "每小时件" ⇒ 舍(出货差 / 秒差 * 3600, 0),
        "样本" ⇒ 出货差
      }
    】
    它 ⇒ 归 空
  】
】

注 ============ 故障分析 ============

匠 算故障分析(库) 【
  注 按位号统计
  {} 名 按位号
  {} 名 按级别
  {} 名 按说明
  0 名 总告警
  0 名 未确认

  遍 警 于 库["告警"] 【
    总告警 + 1 易 总告警
    取(警, "位号", "未知") 名 位
    取(按位号, 位, 0) + 1 易 按位号[位]
    取(警, "级别", "警告") 名 级
    取(按级别, 级, 0) + 1 易 按级别[级]
    取(警, "说明", "") 名 说
    取(按说明, 说, 0) + 1 易 按说明[说]
    判 【 取(警, "已确认", 假) == 假 ⇒ 未确认 + 1 易 未确认 它 ⇒ 空 】
  】

  注 按位号排序（多的在前）
  键集(按位号) 名 位们
  [] 名 位榜
  遍 位 于 位们 【
    增(位榜, { "位号" ⇒ 位, "次数" ⇒ 取(按位号, 位, 0) })
  】
  排(位榜, 节 (x) 【 归 0 - 取(x, "次数", 0) 】) 名 位榜排

  注 按说明排序
  键集(按说明) 名 说们
  [] 名 说榜
  遍 说 于 说们 【
    增(说榜, { "说明" ⇒ 说, "次数" ⇒ 取(按说明, 说, 0) })
  】
  排(说榜, 节 (x) 【 归 0 - 取(x, "次数", 0) 】) 名 说榜排

  注 只取前 10
  [] 名 说榜十
  0 名 计
  循 计 < 最小(10, 长(说榜排)) 【
    增(说榜十, 取(说榜排, 计, {}))
    计 + 1 易 计
  】

  归 {
    "总告警" ⇒ 总告警,
    "未确认" ⇒ 未确认,
    "按位号" ⇒ 位榜排,
    "按级别" ⇒ 按级别,
    "高频故障" ⇒ 说榜十
  }
】

注 ============ 设备效率排行 ============

匠 算设备排行() 【
  判 【 长(分析历史) < 2 ⇒ 归 [] 它 ⇒ 空 】
  取(分析历史, 0, {}) 名 首
  取(分析历史, 长(分析历史) - 1, {}) 名 尾

  取(尾, "大件", 0) - 取(首, "大件", 0) 名 大件差
  取(尾, "小件", 0) - 取(首, "小件", 0) 名 小件差
  取(尾, "超重", 0) - 取(首, "超重", 0) 名 超重差
  取(尾, "出货", 0) - 取(首, "出货", 0) 名 出货差

  0.0 名 大件占比
  0.0 名 小件占比
  判 【
    出货差 > 0 ⇒ 【
      舍(大件差 * 100 / 出货差, 1) 易 大件占比
      舍(小件差 * 100 / 出货差, 1) 易 小件占比
    】
    它 ⇒ 空
  】

  归 [
    { "位号" ⇒ "CY-01", "名" ⇒ "分拣气缸1（大件）", "动作" ⇒ 大件差, "占比" ⇒ 大件占比 },
    { "位号" ⇒ "CY-02", "名" ⇒ "分拣气缸2（小件）", "动作" ⇒ 小件差, "占比" ⇒ 小件占比 },
    { "位号" ⇒ "WT-01", "名" ⇒ "称重传感器", "动作" ⇒ 出货差, "占比" ⇒ 100.0 },
    { "位号" ⇒ "VS-01", "名" ⇒ "视觉识别相机", "动作" ⇒ 出货差, "占比" ⇒ 100.0 }
  ]
】

注 ============ 质量分析 ============

匠 算质量(库) 【
  判 【 长(分析历史) < 1 ⇒ 归 空 它 ⇒ 空 】
  取(分析历史, 长(分析历史) - 1, {}) 名 尾
  取(尾, "到达", 0) 名 到达
  取(尾, "超重", 0) 名 超重
  取(尾, "识别率", 100) 名 识别率
  取(尾, "大件", 0) 名 大件
  取(尾, "小件", 0) 名 小件

  0.0 名 超重率
  0.0 名 大占比
  0.0 名 小占比
  判 【
    到达 > 0 ⇒ 【
      舍(超重 * 100 / 到达, 2) 易 超重率
      舍(大件 * 100 / 到达, 1) 易 大占比
      舍(小件 * 100 / 到达, 1) 易 小占比
    】
    它 ⇒ 空
  】

  归 {
    "识别率" ⇒ 识别率,
    "超重率" ⇒ 超重率,
    "大件占比" ⇒ 大占比,
    "小件占比" ⇒ 小占比
  }
】
